# RiftCast 1.2.3

修复十人经济排行全部显示横线的问题。

- 十人经济排行接入当前直读的累计金币，按全场十名选手排序，金币条使用同一比例。
- 保留数据有效期与游戏时间校验：回放跳转加载期间隐藏旧读数，收到对应时间的有效采样后恢复显示。
- 补充直读金币、过期读数、跳转恢复和 1920×1080 输出配置的回归验证。
- 内置 OBS 的合成画布与输出保持 **1920×1080（16:9）**。

## 下载安装

展开本页 **Assets**，下载唯一安装包 **RiftCast-1.2.3-Setup-x64.exe**。退出旧版 RiftCast 后，双击安装包，按向导安装；升级可沿用原安装位置。完成后从桌面或开始菜单启动 **RiftCast**。

连接国服观战或回放后，在场景库选择“十人经济排行”，预监确认后切入节目。
