# RiftCast 1.0.1

本次更新细化风格包的文字与颜色设置。32 类元素支持独立文字色、底色、边框色、字体预设、字号、字重和字距，并支持逐节目覆盖。首发姓名可以使用深蓝字，GAME 标签可以同时保留白字，解决浅色美术共用白色令牌的问题。

旧风格包继续兼容，原有自定义素材和不可变 revision 保留。旧青花瓷包需要添加元素配置后作为新修订导入；应用不会自动重写已导入素材。详见随附 Style-Packs.md 和 JSON Schema。

## 安装与使用

Windows x64 可下载 RiftCast-1.0.1-Setup-x64.exe 安装，或解压 RiftCast-1.0.1-Windows-x64.zip 后双击 RiftCast.exe。保留 ZIP 中所有文件。五套内置风格继续离线随附。

升级前退出应用并备份 %APPDATA%\RiftCast。导入新风格后先检查独立预览，准备到预监，检查后 TAKE。旧节目快照保持原来的风格修订，可使用撤回恢复。

## 验证与边界

发布工作流执行 Windows 单元测试、类型检查、生产构建、内置素材及固定区域契约检查、11 场景导入预览、五套内置风格浏览器回归和隔离目录中的打包 EXE 检查。元素设置包含覆盖优先级、输入校验、导入导出与重启测试。验证明细随 Release 提供。

这些检查覆盖本地服务、浏览器和打包应用。真实游戏、OBS 推流及平台观众端效果仍需播出环境验收。
