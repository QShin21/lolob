# RiftCast 1.6.0 · 国服 16.22 与应用更新

- 适配国服游戏 `16.22.836.1077` 的十人观战遥测、经济、技能冷却、符文、视野、目标与回放伤害。
- 新版十人回放的输出、伤害分类和承伤已与官方赛后统计核对。
- 在顶部“检查更新”中，一键检查 GitHub 正式版本、下载并校验安装包。已安装版本会在停止输出并退出后自动更新、重新启动；便携版打开安装程序供选择安装目录。
- 保留旧版读取配置与用户数据；未知构建继续提示等待适配。

本轮真实游戏测试使用 `16.22.834.9083` 的十人回放，在 `16.22.836.1077` 游戏进程中播放。新版实时观战尚待现场核验；男爵和远古龙实际持有画面仍需对应场景核对。

## 安装

结束导播输出并退出当前 RiftCast，再运行 Windows x64 安装包。安装版后续可通过客户端顶部的“检查更新”获取正式发布。
