# RiftCast 1.1.0

- 召唤师技能、终极技能与可读取的装备技能支持冷却变暗、顺时针扇形遮罩及最后 10 秒数字倒计时。终极技能使用圆形图标。
- ID 下方增加紫色经验条、绿色生命条、蓝色法力条／黄色能量条。选手名最多 16 字符，汉字按 2 字符计算；超限名称仅截取显示，原始记录保留。个人经济移至状态区与补刀／KDA 之间。
- 死亡头像变为灰度并显示复活剩余秒数。男爵增益显示紫色边框，远古龙增益显示灰白色边框，同时持有时显示双框。
- 伤害统计先保存官方赛后数据，含对英雄伤害、承受伤害及可用的伤害类型拆分，保留来源并支持 JSON／CSV 导出，暂不进入节目画面。实时内存伤害累计尚未接入。
- 内置 Windows 只读观战采样器，设置页显示连接状态。暂停、跳转、旧样本和装备槽位变化会使相关读数冻结或失效，避免继续显示过期状态。
- 补充原生 HUD 的 3、5 数字识别，保留严格颜色、形状和裁切校验。

## 安装与数据

提供 Windows x64 Setup、完整 ZIP、六套可导出风格包、使用说明及 SHA-256 校验清单。程序继续使用原有用户数据位置，保留赛事、素材和配置。

## 兼容与验收范围

当前内存读取仅适配已核对文件哈希的国服 `16.20.824.8524` 游戏版本，且要求可用的观战／回放接口。游戏文件变化时自动停用原生读取，保留可用的官方 API 数据；新版本需要重新适配。读取方式与数据边界详见 [观战遥测文档](https://github.com/QShin21/lolob/blob/new/docs/Observer-Telemetry.md)。

已在本机真实国服回放中确认 1 倍速播放、十名英雄生命／资源／经验／金币、召唤师技能与终极技能冷却、饰品冷却。当前采样片段未出现男爵或远古龙增益，相关边框和复活显示已通过隔离浏览器样例验证，仍需在对应真实事件发生时对照。部分装备被动冷却缺少可读技能槽位，暂不显示。

自动发布流程核对 Windows 测试、构建、六套风格布局、冷却 HUD、打包程序、原生采样脚本完整性和远端资产摘要。真实 OBS 合成、推流及观众端效果需单独验收。回放未关联官方赛后统计时，伤害数据保持不可用。
