# RiftCast 1.1.1

- BP 选人阶段，当前未锁定的卡片横向扩大至同侧其他卡片的约 2.2 倍，并以略高的卡面、侧色光框与阴影形成浮动效果。同侧其余卡片收缩，保持底边对齐。
- 锁定英雄后收回常规卡位，焦点跟随下一个正在选人的位置。禁用、等待客户端、全部选完或最终锁定状态恢复固定布局。保留英雄顺序、中央比分及历史禁用栏。
- 提供独立的小框／放大框英雄图库：173 位英雄，合计 346 张 WebP。小框 360×760，放大框 800×800；使用 Riot 官方加载原画裁切，少数主体偏低的英雄采用独立裁切位置。图片本地随包提供，切换状态时选择对应素材。
- 六套内置与既有导入风格共用动态布局；蓝红卡片底纹现在逐卡铺设，随放大和收缩自适应，高亮沿用风格配色。风格包导出说明同步更新，原有内容指纹及选择保持兼容，无需重新导入。
- 安装程序、完整 ZIP、六套风格包继续提供。另有 `Draft-Art-Compact.zip` 与 `Draft-Art-Expanded.zip` 两个独立素材库，各含 173 张图片及来源、尺寸和 SHA-256 清单。

## 使用

自动 BP 跟随客户端当前选人方与锁定数据。人工 BP 使用对应的选人阶段及当前方设置。升级后先在预监检查所用风格、长名称和英雄构图，再执行 TAKE。全部锁定后卡片恢复统一宽度；系统开启减少动态效果时，尺寸切换直接完成。

英雄素材为共享图库，风格包负责底纹、边框、配色与字体，两套素材 ZIP 无需导入风格包管理器。保留现有赛事、素材和用户配置。

## 验证范围

发布流程包括全部英雄素材的文件／尺寸／哈希核对、六套风格的 BP 动态状态与 1920／1280／960 宽度验证、原有节目回归、Windows 测试及打包程序检查。验证涵盖预选、空框选人、锁定、换边、缺位、禁用、等待和最终锁定，检查卡片边界及小／大图选择。

上述动态状态使用隔离样例驱动，真实客户端 BP 和 OBS／平台播出需要现场核对。1.1.0 的国服观战读取版本与伤害数据边界保持，详情见上一版本说明。
