# 英雄原画素材

仓库随附 Data Dragon 16.19.1 的 173 位英雄，每位包含 BP 竖幅、首发对位竖幅和方形头像，共 519 个 WebP 文件，存放在 `public/champion-art`。节目通过本地路径直接调用，无需在播出时下载或重新裁切。

源素材使用 [Riot Data Dragon 的英雄加载页竖版原画与头像](https://developer.riotgames.com/docs/lol#data-dragon)。加载页原画由 Riot 按每位英雄的原始构图裁切；生成步骤保留完整竖版人物，按 BP（400 × 625）和首发对位（400 × 864）两种卡片画幅预先合成，边缘由同一张原画的模糊背景填充。节目中的英雄卡只缩放整张成品，不再以统一横图焦点裁切。

`shared/champion-art-manifest.json` 记录版本、英雄资料、官方源地址、源 SHA-256、输出尺寸和输出 SHA-256。`shared/champion-art-catalog.json` 是节目调用使用的精简目录，仅携带英雄资料及本地路径，避免将审计清单加载到播出页面。离线英雄目录包含全体英雄；在线目录刷新后仍优先调用本地已准备素材。

维护命令：

- `npm run prepare:champion-art`：按最新官方英雄目录准备素材，复用 `data/champion-art-source` 中的下载缓存。
- `npm run prepare:champion-art -- --refresh`：重新获取官方源素材。
- `npm run prepare:champion-art -- --offline`：使用已缓存原图重建。
- `npm run verify:champion-art`：逐个验证尺寸、完整解码与 SHA-256。

原图缓存位于被 Git 忽略的 `data` 目录，成品和清单随代码提交。新增英雄或官方重绘后重新生成、查看两种画幅的图集并运行检查，再更新素材库。
