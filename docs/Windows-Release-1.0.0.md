# RiftCast 1.0.0 使用与发布说明

## 本版内容

应用内置五套原始风格：冰川极光（默认）、曜金典藏、霓虹脉冲、朱砂墨韵、瓷白竞速。五套共 115 张 PNG，保持原美术清单与规范化图片的内容指纹。安装后直接在场景库选择，支持完整离线素材、独立导出与其他 ZIP 风格导入。

简陋包已退役。新安装、缺省风格和旧版简陋包引用均采用冰川极光；预监、节目和撤回快照同时兼容迁移。已有五套下载包不重复登记，其他有效导入包、赛事、队伍、OCR 数据、比分及自定义场景保留。

切换流程：场景库 → 风格包 → 选择风格 → 准备到预监 → 检查 → TAKE。预监更换不会直接改变当前节目，原生团战视图保持完全透明。固定版式及数据绑定不变。

## 安装和升级

Windows x64 安装包名称为 RiftCast-1.0.0-Setup-x64.exe；免安装包为 RiftCast-1.0.0-Windows-x64.zip。免安装包需要完整解压，保留所有 resources 和同目录文件，双击 RiftCast.exe。运行应用无需另装开发用 Node.js。

升级前退出 RiftCast 与其正在运行的输出，备份 %APPDATA%\RiftCast。ZIP 版本同样使用该应用数据位置，换解压目录不会隔离数据。旧默认风格迁移在启动时发生，不能在正在播出的机器上直接替换安装文件。自定义导入素材位于应用数据的 data/style-packs 子目录，只复制 state.json 无法转移图片。

五套内置资源在应用 dist/style-packs 目录中，启动和打包均检查 SHA-256。不要手动编辑该目录。制作派生包时从风格窗口导出 ZIP，修改清单和图片后导入。详细槽位、容量和透明区域要求见 Style-Packs.md。

## 发布流程与产物

正式 Windows 工作流先执行类型检查、内置素材校验、完整 Windows 测试、报告布局、导入与预监隔离测试，再核对五套内置风格的 65 个节目渲染变体。之后构建 Setup 与 ZIP，启动打包后的 EXE，验证本地服务、五套可选风格、导入导出与重启恢复。

发布脚本只接受当前 new 分支的干净提交，逐项检查构建文件及 GitHub 上传后的 SHA-256，全部通过后才公开 v1.0.0 并设为 latest。失败时不会将该次结果声称为已发布。产物包括 Setup、完整 ZIP、五个独立 riftstyle.zip、release-manifest.json、SHA256SUMS.txt、使用说明、风格规范和 verification.json。

GitHub Release 与 Actions 中的实际记录是构建及发布状态的依据。本说明本身不代表流程已经成功执行。

## 验收边界

本版功能验证使用合成比赛及隔离用户数据。下载测试所需的固定驱动压缩包只用于文件校验，不执行驱动安装。自动验收不进行真实 LoL 比赛接入、平台推流、UAC、驱动注册或真实设备变更。

正式赛事前，仍需在实际 Windows 播出主机核对 OBS 合成预监、系统字体、透明区域、摄像头和音频。安装器安装、升级、卸载、长期录制以及真实观众端结果需要单独现场验收。请核对对应版本的签名与校验记录，不要仅凭文件名信任安装程序。
