- 重新定位十人生命、资源、经验、余额与累计金币、技能槽位、完整符文、精确补刀及视野得分。
- 更新增益结束时间的解码方式，恢复野区刷新计时和双方资源计数。

- 保留国服 16.20 配置，按完整客户端构建和文件校验值选择读取布局；切换构建时清理伤害缓存。

本机已完成新版十人观战连续采样，并对 2,367 个实际伤害包进行客户端解析逻辑交叉校验，覆盖物理、魔法和真实伤害。验证记录见仓库 `docs/CN-16.21-Maintenance.md`。本轮实测覆盖实时观战；新版完整 ROFL 的官方终局总量核对仍由运行时校验执行。

## 下载与安装

展开本页 **Assets**，下载唯一安装包 **RiftCast-1.4.1-Setup-x64.exe**。退出正在运行的 RiftCast，双击安装包并按提示完成更新，然后从桌面或开始菜单启动 RiftCast。

进入国服观战或回放后，在“设置 → 数据 → 观战遥测”确认显示“国服只读遥测已连接”。实时观战分片就绪后，状态会追加“实时观战伤害”。

现有赛事、风格包与导播设置会继续使用。安装包用于 Windows x64，无需另装 Node.js 或 Python。
