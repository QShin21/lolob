# RiftCast 0.8.1

## 更新内容

- 通过 Windows 图像识别读取原生观战计分板的视野得分、剩余金币、括号内总经济与补刀数量，并加入局内计分板：饰品侧显示视野，选手名字下显示 `剩余金币(总经济)`，内侧显示补刀。
- 改进数字列定位、分栏放大、颜色过滤及重复识别校验，减少赏金文字、彩色框和死亡倒计时干扰。英雄头像与同队阵容用于确认选手身份；无法确认的数据保持不可用。
- 视野和个人统计采样超过 3 秒回退到可用 API 数据；个人 OCR 经济超过 10 秒失效，避免长期保留旧值。
- 延续 0.8.0 的透明原生顶部队名/胜场扩展、采样图载入修复、旧版首发对位布局。

## 使用方法

双击 `RiftCast-0.8.1-Setup-x64.exe` 安装，或解压 `RiftCast-0.8.1-Windows-x64.zip` 后运行 `RiftCast.exe`。升级沿用用户目录中的赛事与配置。

连接局内 API 和游戏画面，启用个人观战识别，展开原生底部计分板并切换到金币列。绿色区域应显示类似 `393(4343)` 的余额与总经济，视野和补刀列应完整可见。来源与校准中的个人区域需包含两队五行、最外侧视野列及中间英雄头像。OBS 优先提供原始采样；屏幕回退时需保持游戏窗口完整可见。
