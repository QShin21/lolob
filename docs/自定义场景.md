# 自定义场景

在「导播工作台 → 场景库」点击 **新建自定义场景**。创建、编辑和删除由当前主导播席执行。

1. 填写场景名称和背景颜色。
2. 点击「上传图片」，或从已有素材库添加图片。支持 PNG、JPEG、WebP、GIF，单张上限 8 MB。
3. 添加应用画面时，先连接 OBS 引擎并打开目标应用，点击「刷新来源」，选择进程 / 应用窗口，再点击「添加窗口」。窗口需要保持可见；远程桌面需要保持连接，部分应用在最小化或桌面会话断开后会停止提供画面。
4. 「已有 OBS 来源」可以添加已在 OBS 中配置的摄像头、媒体、浏览器等输入。它引用原来源；在 OBS 修改该来源的内容也会影响使用它的场景。此入口不创建新的媒体文件或摄像头设备配置。
5. 选择图层后，调整横向位置、纵向位置、宽度、高度、适配方式及显示开关。画布坐标为 1920 × 1080；图层列表上方覆盖下方，可以上移、下移、铺满画布或移除素材。
6. 点击「保存场景」，在场景库选择该场景作为预监。核对 OBS 实时合成后按 **Enter / TAKE** 切入节目。

编辑器中的窗口和 OBS 来源显示排版占位；主预监显示实际 OBS 合成。保存和编辑只更新待播配置，节目采用上次 TAKE 时的场景快照。对正在播出的场景保存修改后，需要再次 TAKE 才会更新节目。

窗口捕获关闭鼠标显示和独立应用音频捕获。内置引擎的自定义节目沿用桌面音频、解说麦克风的现有混音设置；已有 OBS 来源沿用自身音频设置。切入后仍需回听声音。

场景支持「自定义」分组、常用收藏、手机端预监选择和串联单。最多保存 50 个自定义场景，每个场景最多 24 个素材。正在播出或被串联单引用的场景需要先解除引用，再删除；删除场景保留已上传图片。

数据随现有状态文件持久化，默认位于 `data/state.json`，图片位于 `data/uploads/`；设置 `RIFTCAST_DATA_DIR` 时随对应数据目录保存。旧版本状态没有自定义场景时继续使用原有内置场景。内置引擎启动后会尝试恢复已保存的自定义节目，素材不可用时显示失败提示，待导播核对后重新 TAKE。

若图片文件、应用窗口或 OBS 来源已不可用，准备新节目会失败，并保留此前节目配置。窗口在播出期间关闭时，其捕获画面仍取决于 OBS 和目标应用；请及时选择备用场景。
