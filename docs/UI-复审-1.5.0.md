## 复审中新发现的问题与闭环

### 设置搜索的键盘路径

问题出现在当前任务未包含于搜索结果时。原实现只给当前任务 `tabIndex=0`，因此搜索“声音”而正文仍为“输出”时，唯一结果的 `tabIndex=-1`，Tab 从清空按钮直接跳到“返回导播台”。

实施者在 `src/pages/Settings.tsx` 增加 `directoryTabStop`，为当前可见项或首个结果提供 Tab 入口。独立复验记录到结果角色为 `tab`、文本为“声音”、`tabIndex=0`，按 Enter 后正文标题同步变为“声音”。

### 五人队伍摘要的滚动边界

原摘要高约 555px，父详情面板高约 348px，溢出内容与底部状态带重叠。第四名选手在整页滚动时持续受到遮挡。问题截图保留为 `team-scroll-repro.png`。

实施者在 `src/operator-150.css` 将摘要设为占满剩余空间的 flex 容器，并将名单设为独立滚动区。最终摘要高约 346px，名单可视区约 177px；滚至末尾时第 5 行位于 y≈485～554，名单容器底部 y≈572，中心命中测试命中该选手行。见 `fixed-roster-last-player.png`。

### 触控与局部视觉收口

远程回放“事件识别与采集范围”和主导播“配置按钮与多组快捷键”的原热区分别为 18px、21px 高，最终均为 44px。其他可见远程折叠入口也实测 44px。底部四个输出标签恢复为 12px，原生 HUD 正文与标题内边距对齐。相关实测见 `closure-probe.json`。

## 保存与媒体边界

独立保存回归使用真实隔离 HTTP 服务完成以下流程：

1. 在“身份与品牌”填写临时品牌，仅保留本地草稿。
2. 切到“赛前倒计时”，保存独立倒计时。
3. 返回身份任务，界面提示配置冲突；执行“核对后保留本地修改”。
4. 保存基础包装，确认品牌更新且倒计时仍保留。
5. 恢复原品牌，清除测试倒计时。

请求记录共 4 次 `set-overlay`，字段依次为 `countdownEnd`、`sponsor`、`sponsor`、`countdownEnd`，每次包含 `expectedConfigVersion`。整个流程没有发送 TAKE。测试后原品牌和倒计时状态已恢复，配置版本按实际保存次数正常递增。

主题边界另通过实图和样式核验：

- PGM 与 PVW 排版画布的整棵计算样式在深浅主题之间一致。
- PVW 深浅画布 PNG 哈希相同；独立 `/overlay` 深浅 PNG 哈希相同。
- PGM 初始两张正常渲染图有 20 个低幅像素差异，最大单通道差为 2；稳定重绘后的深色与浅色 PNG 哈希相同。原始和稳定结果均保留于 `final-media-boundary.json`。
- 操作层的背景、按钮和字体随主题变化；节目画布、固定媒体配色及 HUD 输出保持自己的样式。

阶段抓图曾出现一次浅色未连接占位空白，独立新建页面及最终正常渲染截图中提示均完整显示，内部文字样式也一致。该现象没有列为已确认应用缺陷。

## 布局与验证边界

1366×768 每个监视媒体区域约 313×176；1366×736 约 256×144；1440×900 约 492×277；1920×1080 约 519×292。比例保持 16:9。在低高度桌面，双监视、切入带和两整行场景可以同时使用；大窗口提供更大媒体区域。1093×614 与 910×512 的内容按断点纵向重排，页面没有水平溢出。

独立第一轮 98 张全量抓图与修复回归均未收到浏览器 `pageerror`，所查主页面和远程页面没有页面级水平溢出。当前 fixture 的实时名单与素材为空，因此非空十人数据、8 队与20素材的补充视觉核对使用实施者真实样本截图，并与源码结构相互核对。

本结论覆盖源码对应的浏览器操作 UI、隔离样本交互、真实草稿保存请求与媒体主题边界。本轮没有启动 OBS、连接真实游戏、安装驱动、真实推流或操作物理音视频设备；手机软键盘实机、Electron 原生投影窗口、封装安装器和平台观众端效果由各自验收环节确认。
