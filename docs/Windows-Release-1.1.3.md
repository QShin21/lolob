# RiftCast 1.1.3

修复局内计分板三条状态条、技能和装备冷却缺失，以及“回到比赛”后持续等待 OBS 回执的问题。

## 计分板遥测恢复

国服 Live Client Data 在同一局中可能同时返回 `game_character_displayname_Aatrox` 与 `Character_Aatrox_Name` 两类英雄标识。旧版本只识别第一类，遇到第二类时整组十人遥测校验失败，导致血条、经验条、资源条为空，终极技能灰显，召唤师技能和装备冷却没有覆盖到图标上。

现在两类标识统一转换为英雄 ID，并用于选手匹配及装备槽位校验。三条状态条、终极技能、召唤师技能和装备冷却随有效样本恢复，继续采用变暗、扇形遮罩和最后 10 秒数字的显示规则。保留同阵营、等级、时间和槽位一致性检查。

已使用包含剑魔的真实国服观战验证：十人的生命、经验、资源与技能状态正常进入输出，连续采样确认终极技能、召唤师技能、装备与饰品冷却变化。另有混合标识和装备槽位回归测试。

## OBS 切入回执

修复点击“回到比赛”或使用对应快捷键后，界面一直显示“等待 OBS 应用本次切入”、后续 TAKE 按钮锁住的问题。OBS 确认恢复比赛场景和音频后，回执立即更新为“已应用”；失败操作保留此前节目与回执。回归测试覆盖成功后继续 TAKE、失败保留原节目及音频恢复。

## 更新说明

保留 1.1.2 的实时团战伤害、中立资源计时、赛后伤害对比，以及全部六套风格和三套 BP 素材库。国服只读遥测配置仍对应游戏构建 `16.20.824.8524`。

安装更新后核对预监并重新 TAKE。发布流程验证 Windows 安装包、数据恢复及各风格布局。
