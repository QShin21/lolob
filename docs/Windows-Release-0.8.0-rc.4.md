# RiftCast 0.8.0-rc.4：抖音窗口采集

连接与输出 → 输出 → 抖音直播伴侣，默认使用「窗口采集」。连接内置 OBS 后点击「打开节目输出窗口」，桌面出现独立的「RiftCast 节目输出」。它显示完整 Program 合成画面，包括游戏、图片、字幕和 HUD；预监编辑经 TAKE 后进入节目。

在直播伴侣添加「窗口」素材，选择「RiftCast 节目输出」（进程为 obs64.exe）。关闭鼠标显示，优先使用默认采集方式，核对客户区画面及比例。保持窗口打开且不要最小化，推荐放在第二块显示器；兼容性捕获可能包含周围桌面，请检查预览后再使用。调整窗口大小会影响可采集像素尺寸。

窗口本身只提供视频。将输出路径设为抖音，点击「准备节目音频设备」，设备就绪后点击「启动伴侣节目混音」。直播伴侣麦克风选择基础双声道 CABLE Output，并关闭重复的系统声与原麦克风。先试听，再在直播伴侣开播。

切换 RiftCast 页面或刷新界面会保留独立节目窗口。关闭该窗口不会关闭导播台监视器，也不会停止节目混音。下播时先在伴侣结束直播，然后停止混音、关闭节目窗口。退出 RiftCast 会关闭它启动的引擎和节目窗口。窗口关闭后再次打开需要在伴侣检查采集目标。

虚拟摄像头路径仍可手动选择；此次窗口模式不依赖虚拟摄像头格式协商，也不会自动启动虚拟摄像头或直播间。

验证边界：原生窗口、Windows 采集像素、页面生命周期和音频控制有独立验证；实际抖音预览、声音同步及观众端接收以现场测试为准。安装程序未签名，赛事数据沿用用户目录。
