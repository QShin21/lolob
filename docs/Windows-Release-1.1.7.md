# RiftCast 1.1.7

首发对位支持十名选手的完整六符文展示。

- 国服观战与回放直接读取每名英雄的主系四符文、副系两符文，并保存三个属性碎片。
- 首发对位按主系、副系顺序展示六个实际选择，主副系之间增加间隔，适配六套内置风格。
- 按英雄与阵营匹配数据，并与游戏接口提供的基石、主系、副系核对。完整数据暂不可用时，展示已确认的基石。
- 保留赛后报告卡片的紧凑符文排版。

当前读取配置适配国服游戏构建 16.20.824.8524。已在真实运行的国服回放验证十名英雄：60 个符文与 30 个属性碎片均与官方记录一致。

## 下载安装

1. 展开本页 **Assets**，下载唯一的安装包 **RiftCast-1.1.7-Setup-x64.exe**。
2. 升级前退出正在运行的 RiftCast，双击安装包，按向导完成安装；升级可沿用原安装位置。
3. 从桌面或开始菜单启动 **RiftCast**。打开国服观战或回放，等待数据连接后，在场景库选择“首发对位”，检查预监并切入节目。

符文图标随安装包提供，无需单独下载素材或风格包。
