## 复现检查

```powershell
npm ci
npm test
npm run build
node scripts/ensure-electron.cjs
npm run setup:obs
node scripts/test-obs-projector-helper.cjs
```

以下界面脚本需要另行提供 Playwright；设置 RIFTCAST_PLAYWRIGHT_MODULE 为该模块的绝对路径，或在工具环境中安装它。HUD 像素核对还需要带 Pillow 的 Python，可用 RIFTCAST_PYTHON_EXECUTABLE 指定解释器。它们属于开发检查工具，常规启动使用 package-lock.json 中的依赖。

```powershell
npm run verify:production
npm run verify:broadcast-controls
npm run verify:champion-art
node scripts/verify-director-workflow.mjs
node scripts/verify-lpl-hud.mjs
node scripts/verify-game-clock.mjs
```

原生辅助程序的源码与当前可执行文件都随仓库提供。需要重编译时，使用 MinGW-w64 g++，可通过 RIFTCAST_CXX 指定编译器，再运行 node scripts/build-obs-projector-helper.cjs。

## 现场演练

1. 双击启动导播.vbs，确认内置 OBS 与工作台连接；导入赛事、战队、首发和素材。
2. 在自定义比赛中完成 BP 与全局禁选，检查换边和跨局历史。
3. 核对实际游戏捕获、顶部遮挡、底部表格、英雄属性区域和小地图。配置两侧图片或物理摄像头并核对裁切。
4. 保持观战计分板采集区可见，核对十名玩家身份、KDA、补刀与经济读数。缺失、歧义及超过有效期的读数保持未知。
5. 重新打开已启用 Replay API 的录像，核对暂停、倍速与跳转后数据重置。
6. 完成一局，检查自动归档、胜方确认、BO 比分、冻结报告、下一局及历史导出。
7. 使用本次平台地址完成本地录制与实际推流，检查声音、接收端画面、丢帧与音画同步。核对本地输出后，再确认直播平台上线。
