# RiftCast 1.5.0 · 导播工作台 UI 全面更新

本版更新导播软件的操作界面与工作流程，统一深浅主题、页面导航、表单控件和状态提示。

- 采用石墨深色与浅瓷白主题，统一文字、图标、按钮、工作面和键盘焦点。
- 重排导播主台的监看、下一次切入、TAKE 与场景库；保留场景搜索，改善小窗口下的场景选择。
- 连接与输出按任务分组并支持搜索；节目包装拆分为六个子任务，明确保存范围。
- BP 工作入口前移，声音页优先显示节目混音，减少常用操作的滚动距离。
- 改善队伍资料、赛事创建、帮助跳转和手机遥控的操作路径。
- 修复浅色主题中资源进度、权限提示、诊断等区域的文字对比度。
- 保留 1.4.2 的 OBS 切入与转场修复，以及现有赛事、素材和数据能力。

## 下载与安装

展开本页 **Assets**，下载 **RiftCast-1.5.0-Setup-x64.exe**。结束当前输出并退出 RiftCast，双击安装包完成更新，然后从桌面或开始菜单启动 RiftCast。

安装包适用于 Windows x64，无需另装 Node.js 或 Python。升级后继续使用现有赛事、素材和导播设置。

安装后可从左侧主题按钮切换深浅外观；在“连接与输出”中搜索任务，进入“节目包装”后选择对应子任务。准备好场景后，核对预监，再点击 **切入节目**。
