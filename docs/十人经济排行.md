# 十人经济排行

工作台中的「十人经济排行」使用 G 预监、Enter 切入，也可在画面详情中直接切入。双方十名选手参与同一个累计经济总榜，从高到低排列；左列为第 1–5 名，右列为第 6–10 名。每行包含名次、英雄头像、选手名称、队伍、经济条和完整金币数字，蓝、红条形颜色对应所属队伍。两列共用榜首金额作为条形长度基准。

实时对局使用原生观战计分板 OCR 的累计金币，或客户端明确提供的 `totalGold`。当前可花费金币 `currentGold` 与装备价格均不参与排名。缺少、过期、回放跳转等待新采样的金额显示“—”，排在可用数据之后；可用金额为 0 时保留真实的 0。同金额按选手 ID 稳定排序，避免客户端名单顺序改变导致跳动。

该节目随有效采样实时更新，可在任意比赛时刻调用。十分钟分类卡、分类采集、自动快照和 `/api/player-income/telemetry` 接口已移除；旧保存状态中的 `income` 场景会迁移到 `gold-ranking`。团队经济采集、经济曲线、个人累计经济 OCR 继续供现有节目使用。

运行 `npm test` 检查排序、有效期、零值、同金额顺序和场景迁移。具备 Playwright 与 Chromium 的验证环境中运行 `npm run verify:broadcast-controls` 检查两列画面与切入；可用 `RIFTCAST_PLAYWRIGHT_MODULE` 指定已安装的 Playwright 入口。浏览器检查使用演示/隔离数据；真实游戏 OCR 和直播接收端效果需要实际对局验证。
