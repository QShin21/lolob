# RiftCast 0.9.4 · 场景风格包

本版将 11 个预设节目的既有外观整理为第一个风格包「简陋包」，增加场景库中的风格包管理、ZIP 导入、导出、逐节目预览与待播切换。赛事数据接口、BP、英雄素材、自定义场景和原有转播工作流继续使用。

## 下载与安装

RiftCast-0.9.4-Setup-x64.exe 是 Windows x64 安装程序。RiftCast-0.9.4-Windows-x64.zip 是解压运行版本，解压后启动 RiftCast.exe。应用包含运行环境与 OBS，无需另装 Node.js。保留与应用一起分发的第三方声明、对应 OBS 源码和音频组件许可。

升级前退出旧版并备份应用数据目录。旧配置缺少风格字段时自动使用简陋包，不需要重新设置赛事资料。解压版应解压到新目录，避免覆盖正在使用的程序。

## 切换赛事美术

进入导播台，在场景库点击「风格包」。选择已有包，使用右侧的「预览节目」检查赛前、BP、局内、赛后等画面。「准备到预监」将风格放入待播配置，当前节目保持原风格。返回导播台核对预监，执行 TAKE 后上节目。

「导入风格包」接受固定格式 ZIP，导入本身不会改变预监和节目。仅当前主导播可以导入与切换。素材和所选版本保存在应用数据目录，重启后仍可使用。安装同 id 的新版本不会覆盖已上节目的旧版本。

## 制作风格包

下载 RiftCast-0.9.4-Jianlou.riftstyle.zip，或在风格窗口导出简陋包。解压后修改 manifest.json 中的 id、name、version，以及 assets 中的美术图。将清单与 assets 文件夹一同压缩到 ZIP 根目录即可导入，无需修改程序源码或重新打包应用。

格式为 riftcast-style-pack/schemaVersion 1，画布为 1920 × 1080。支持 PNG、JPEG、静态 WebP，ZIP 最大 48 MiB。配色和固定贴图槽可编辑；数据元素位置保持现有版式。局内、BP 和采访保留透明视频采集区，团战场景保持游戏原生全透明 HUD。

完整规范见同页 Style-Packs.md 与 style-pack-v1.schema.json。英雄、队伍和选手信息由实时数据继续绘制，请勿把会变化的文字、比分或英雄烘焙到背景里。

## 完整性和范围

SHA256SUMS.txt 与 release-manifest.json 记录安装包、便携包、风格模板的 SHA-256，以及实际构建源提交。verification.json 汇总发布前自动化检查。损坏或不支持的 ZIP 会拒绝安装；失效的已保存风格在重启时回退并提示。

发布验收使用合成对局数据、隔离工作目录和浏览器，不开启真实平台推流，不安装音频驱动。本版功能仍需在赛事使用的 Windows 主机上核对最终 OBS 预监、字体、游戏采集与透明区域。Windows 可能对未签名安装包提示发布者未知，下载后请先校验 SHA-256。
