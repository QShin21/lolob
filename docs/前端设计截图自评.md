# 本轮界面截图与自评

这是 Astra 实施阶段的设计证据，不是 Sol 完整验收结论。基线仅为当前 main `7f2f39981b7e91d33d6d32e47d1c2003f2c81296`，没有使用已删除重构的截图或布局。新图来自本次 `new` 源码；[捕获记录](evidence/frontend-design-round1/new-capture.json) 附所有 src/shared/server 和锁文件的 SHA256，供交接时核对。

环境为 Linux 系统 Chromium、独立 `/tmp/riftcast-design-*` 数据目录、离线 HTTP 服务。图片来自脚本生成的“DESIGN FIXTURE”；窗口图层是明确标注的测试占位。没有启动 OBS、摄像头、音频桥、推流、录制或安装程序。非 GET 的 `/api/obs/**` 另被捕获脚本拦截，页面设备状态均按真实离线响应呈现。

1366×736 是为 1366×768 扣除约32px标题栏的设计近似，不代表真实 Windows 标题栏、缩放或 DPI 测试。1440×900 和1920×1080为浏览器视口尺寸。移动截图为390×844、localhost已验证且持有控制权的主导播；不能外推为五席或局域网全部通过。

最后收紧“席位未验证时不显示可写操作”后，隔离首次进入发现旧主数据请求可能早于席位建立，造成主导播一直等控制权。已在席位验证后只读刷新 `/api/state`，以服务器实际控制者更新界面；没有把 director 角色直接等同于控制权，没有修改后端授权规则。重跑首进流程确认可以进入编辑器。此处仍需要 Sol 覆盖控制转移、断线和服务重启。

## 有限交互证据

同一隔离构图的画布实测约748×420.75px，对应1920×1080：图层起点为(1370,440)，20×12 CSS像素拖移换算后变为约(1421,471)。右方向键增加1px，Shift＋下方向键增加10px。右下角16×8 CSS像素缩放将430×350变为约471×371。具体前后值写在捕获记录中，另有[操作后截图](evidence/frontend-design-round1/new-editor-local-manipulation-1366x736.png)。随后放弃本地草稿，没有保存、选择新预监或TAKE。

这些只用于确认设计稿接了真实本地编辑状态。所有八柄、缩放后的坐标、负坐标/超画布、来源更换、24层/50场景、冲突、权限撤销与快照仍交Sol完整验证。此前捕获工具曾因页面构建尚未包含Remote、React提交前立即取值、动态定位器计数变化而调整；这些失败不记作通过结果，最终JSON只记录完整成功捕获。
