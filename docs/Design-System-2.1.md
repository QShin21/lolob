# 观澜 2.1 设计系统 ·「墨与信号」

2.1.0 重做了导播工作台的全部界面样式。旧版叠加的多层样式表（`styles.css`、`director.css`、`operator-150.css`、`theme-2/*` 等）已删除，控制台界面统一由 `src/ui/` 与各页面自己的样式文件组成。节目画布、风格包和 `/overlay` 输出保持原样，逐像素与 2.0.0 一致。本文是界面改动的依据。

## 设计意图

观澜取自“观水有术，必观其澜”。导播在暗场里看两块监视器，手边是切入键。界面要像一台仪器：安静、精确，把注意力留给画面。

1. **色彩只属于信号。** 界面骨架只用墨与纸两种无彩色。色相只出现在有含义的地方：朱砂红代表正在播出（PGM），石绿代表预监与就绪（PVW），琥珀代表待处理与警示，玫红代表错误，蓝与红代表两支队伍。主按钮、选中、焦点一律用明度表达：深色主题是纸白实底，浅色主题是墨色实底。
2. **面板靠明度分层，描边只留给需要它的地方。** 画布最深，面板亮一级，控件再亮一级。面板无描边、无投影，彼此间隔 8px。面板内部用间距和发丝线分组，面板里不再套卡片。有描边的只有三类：文本输入框（3:1 对比的边框用来识别控件）、键盘焦点、监视器与场景的 Tally 框。
3. **一处宋体。** 思源宋体只用于品牌字标、顶栏页面标题和对话框标题，是产品的文气所在。其余文字全部用 IBM Plex Sans 配思源黑体，数字读数用 IBM Plex Mono。
4. **监视器是主角。** 导播台里两块监视器占最大面积，也是唯一带粗色框的元素。
5. **静。** 过渡 120–180ms，只表达状态变化。唯一的编排动效是启动屏上那道水纹。

规则：

- 控制台样式里的颜色一律引用令牌。媒体区域（监视器、视频预览、截图）在两套主题下都保持固定的近黑底 `#050607`。
- 实底信号色上的文字用 `--gl-on-signal`（白）。浅底（`-wash`）上的文字用对应的信号文字色。
- 状态不能只靠颜色：配合文字、图标或位置。
- PGM 红与红方红同屏时，PGM 用实底 Tally 标签，红方只用文字色或细条。
- 信息提示没有专属色相，用次要文字色配图标。

## 字体

| 角色 | 字体 | 令牌 |
| --- | --- | --- |
| 界面文字 | IBM Plex Sans 400/500/600，中文回退思源黑体可变字体 | `--gl-font` |
| 标题与字标 | 思源宋体可变字体 700–900 | `--gl-font-title`（类名 `.gl-title`） |
| 读数 | IBM Plex Mono 500/600：计时、时间码、dB、快捷键、版本号 | `--gl-font-mono`（类名 `.gl-num`） |
| 紧凑标签 | IBM Plex Sans Condensed 500/600：PGM / PVW 标签、队伍缩写 | `--gl-font-cond` |

字号：12（辅助，下限）、13（紧凑正文、按钮、表格）、14（正文）、16（面板标题）、20、22（顶栏页面标题，宋体）、34（大读数）。正文行高 1.5，标题 1.3。字重只用 400、500、600；宋体标题 800，启动屏字标 900。数字默认等宽（`tabular-nums`）。标签用正常大小写，缩写（PGM、PVW、RTMP、REC）保持原样。五套字体随应用离线打包，许可为 SIL OFL 1.1。

## 形状、间距与动效

- 圆角：面板 12px，控件 8px，标签 5px，对话框 14px。
- 间距取 4 的倍数：面板间距 8px，面板内边距 16px（紧凑处 12px），组内 6–8px，组间 12–16px。
- 控件高度：默认 34px，紧凑 32px，TAKE 44px。可点击区域不小于 32×32px，手机席位不小于 44px。
- 投影只用于顶层浮层：对话框、气泡、提示条。
- 过渡 120ms / 180ms，缓动 `--gl-ease`，只改变颜色与 1px 位移。尊重 `prefers-reduced-motion`。
- 焦点：2px `--gl-focus` 实线，偏移 2px，所有可聚焦元素一致。

## 页面骨架

```text
┌────┬──────────────────────────────────────────────────────────────┐
│标志│ 页面标题（宋体）        [ AZR 1:0 EMB · 第 2 局 ]     席位 · 同步 … │ 顶栏 52px
│导航│──────────────────────────────────────────────────────────────│
│    │ 页面内容：若干面板，间距 8px                                   │
│    │                                                              │
│主题│──────────────────────────────────────────────────────────────│
│版本│ PGM 场景·回执 │ RTMP 摄像头 声音 REC │ 回到比赛 技术暂停 核对 │ PVW 场景·待播 [切入节目] │ 播出条
└────┴──────────────────────────────────────────────────────────────┘
```

- 导航栏和顶栏直接落在画布上，没有底色。播出条是一块面板，所有页面位置相同。
- **切入节目（TAKE）只在播出条右端出现**，左侧紧邻 PVW 场景与“N 类待播变化”，点击后者查看本次待播内容。它是界面里唯一的大面积朱砂红实底。
- 顶栏已显示页面标题，页面内部不再重复标题；保留的 `<h1>` 仅供读屏使用。
- 页面第一行是高 36px 的上下文行：左侧一句次要文字说明当前对象，右侧放页面级页签或工具。之后是面板。
- 页面内部滚动发生在面板里，页面本身不出现第二条滚动条。

## 文件结构

```text
src/styles.css             全局入口：按顺序引入下列文件
src/broadcast-base.css     节目画布沿用的元素默认值（冻结，不随界面改动）
src/ui/tokens.css          令牌（深色、浅色）
src/ui/base.css            控制台元素默认值：字体、焦点、输入、表格、对话框
src/ui/components.css      公共组件
src/ui/shell.css           导航栏、顶栏、播出条、启动屏
src/ui/studio.css          导播台：监视器、场景库、临场工作区外框
src/components/*.css       各组件自己的样式，由组件文件引入
src/pages/*.css            各页面自己的样式，由页面文件引入
```

## 边界

- **节目输出不变。** `.broadcast-container` 及其后代、`/overlay` 各输出页、风格包贴图保持各自的色彩、字体与版式。`src/broadcast-base.css` 冻结了它们依赖的元素默认值；控制台的元素规则都排除了 `.broadcast-container` 内部。界面改动后用全部内置风格 × 全部场景的输出截图与上一版逐像素比对。
- 控制台元素规则的作用域是 `.app-shell`、`.remote-workbench`、`.loading-screen`，并用 `:where()` 保持零特异性，页面样式用单个类名即可覆盖。
- 布局尺寸、可点击区域、首屏可见性与键盘流程由 `scripts/verify-operator-ui-150.mjs` 校验；主题切换与节目配色隔离由 `scripts/verify-ui-theme.mjs` 校验。

## 品牌标志

标志是一枚朱砂圆点悬在两道水纹之上：既是水面上的日出，也是信号上方的播出指示灯。水纹跟随当前文字颜色，圆点固定为朱砂红。矢量源文件是 `brand/guanlan-icon.svg`，16 至 32 像素使用简化稿 `brand/guanlan-icon-small.svg`；界面内由 `src/components/BrandMark.tsx` 绘制。`npm run brand:art` 重绘安装向导侧栏、页眉和横幅，`npm run brand` 生成应用图标。
