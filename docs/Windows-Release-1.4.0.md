# RiftCast 1.4.0

新增导播分析图形、可视化风格编辑、镜头制作、赛季统计及制作接口。本轮按 LeagueBroadcast 官网功能页、组件预览与更新日志逐项核对，完整记录见 [功能对照表](https://github.com/QShin21/lolob/blob/new/docs/leaguebroadcast-comparison-2026-10-22.md)。

- **节目包装**：全高 BP、双侧英雄状态栏；经济效率、参团率、英雄伤害与类型构成、等级经验、团战伤害时间线；击杀与事件播报、水晶恢复计时、扩展顶部比分和 L 形品牌布局。L 形布局会同步调整 OBS 游戏来源。缺测值保持空缺，回放跳转后等待新样本。
- **风格编辑**：在风格包管理中打开可视化编辑器，选择或拖动图层，修改字体、颜色及场景布局；支持吸附参考线、连续撤销/重做和动态文字；保存生成独立版本，再准备到预监并 TAKE。
- **镜头制作**：关键帧捕获、线性/样条轨迹、原生回放序列播放、手柄映射与事件跟随。桌面版另可编辑并启用后台快捷键及自定义解说按钮，启用与触发均核对主导播控制权。
- **赛后图形**：独立全屏队伍数据、伤害、经济曲线、系列赛逐局结果、Fearless 分路历史与英雄树；装备事件按已采集原始时间线显示。
- **战斗分析**：基于现有逐次伤害采集补齐最近 15 秒伤害流向、死亡前 12 秒来源及类型回顾、目标 5 秒 DPS 窗口、历史团战选择和图形；资源增益期间可显示 Power Play 净经济收益。
- **节目转场**：硬切、淡化及视频 Stinger；按游戏事件配置自动切入规则，默认关闭，执行后显示实际 OBS 回执。
- **远程选手画面**：生成 VDO.Ninja 邀请与固定分路浏览器来源，依据已确认名单自动绑定；邀请链接由导播分发。
- **演示与资源**：独立图形演示、版本目录匹配、素材下载进度及受保护的过期缓存清理。
- **皮肤与 BP 统计**：十人皮肤名称和原画，按实际皮肤编号匹配目录；BP 可选择全部归档、当前赛事或指定赛事，显示英雄选用率、禁用率、胜率及各自样本数。
- **应用维护**：帮助页可检查正式新版、查看下载进度、取消和重试；顶部可查看并导出本机脱敏故障报告。首次引导可跳过，也可从帮助页重新打开。
- **赛季统计**：按赛事、队伍及选手查看排行、选禁率、交手记录和统计样本覆盖；提供独立排行与选手聚焦浏览器源。统计使用已归档的比赛数据。
- **观众互动**：接入 Twitch 后读取频道现有投票与预测，支持通过聊天消息进行本地计票，并提供独立观众图形。
- **数据集成**：带密钥的 JSON/SSE 比赛数据、可配置来源列表、带 HMAC 签名与重试回执的 Webhook；自定义场景可加入 HTTP(S) 浏览器来源。[接口说明](https://github.com/QShin21/lolob/blob/new/docs/Custom-Overlay-API.md)。

## 下载安装

展开本页 **Assets**，下载唯一安装包 **RiftCast-1.4.0-Setup-x64.exe**。退出旧版 RiftCast 后双击安装包，按向导安装；升级可沿用原安装位置。安装完成后，从桌面或开始菜单启动 **RiftCast**。

## 新功能入口

1. **连接与输出 → 节目包装**：选择分析面板和事件图层，保存到待播并核对预监。
2. **风格包 → 可视化编辑**：编辑并保存独立风格版本。
3. **连接与输出 → 镜头制作**：连接本地回放 API 后抓取镜头关键帧；手柄与后台快捷键分别显式启用。
4. **赛事与素材 → 赛季统计**：选择统计范围，复制排行或选手聚焦链接供浏览器来源使用。
5. **赛事与素材 → 赛后图形**：选择存档、图形模式与页码，复制固定对局身份的浏览器来源链接。
6. **连接与输出 → 观众互动 / 数据集成**：分别填写 Twitch 授权或生成只读数据密钥、配置 Webhook。
7. **连接与输出 → 转场与事件 / 远程选手画面 / 图形演示 / 资源维护**：分别管理转场规则、VDO.Ninja 邀请、模拟预览及离线素材。
8. **赛事与素材 → 比赛安排 / 战队选手**：按需启用自动阵营识别，填写完整 Riot ID；双方各有至少三个唯一账号匹配后才自动换边，节目身份通过 TAKE 更新。
9. **帮助 → 应用版本与下载 / 重新打开首次引导**；顶部 **故障报告** 可生成本机报告。

官网中游戏世界三维资产、单客户端原生多视角、跨实例镜头同步，以及惩戒反应、逐技能伤害归因仍有能力或采集缺口，已在对照表列出。云备份与同步按用户要求跳过。

自动化验证覆盖计算、权限、持久化、隔离服务、浏览器界面及打包程序。Twitch 和游戏镜头控制使用模拟接口验证，尚未完成真实账户、实际游戏与手柄、OBS 播出及直播平台的现场联调。后台快捷键默认每次启动关闭。新增逐次伤害分析沿用已支持的观战/回放解析版本；缺少对应采样时显示等待或数据不完整。
