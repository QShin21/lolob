# RiftCast 1.1.5

## 本次更新

- 修复选手画面轮播被比赛暂停、旧版保持状态或节目场景拦住的问题。比赛暂停与选手画面轮播分别控制，预监和节目各自按场景运行；点击“恢复 5 秒轮播”即可解除人工保持。
- PGM、PVW 分别显示实际轮播倒计时或保持原因，手动选择仍需核对后切入节目。
- 国服观战直接读取视野得分、KDA、精确补刀，以及防御塔、元素龙、远古龙、男爵、虚空巢虫和峡谷先锋计数。撤下辅助 OCR 设置，已有 OCR 开关不会覆盖直接采集的数据。
- 资源计数直接取自当前观战状态，支持回放跳转。新增峡谷先锋和远古龙的赛后报告行，相关数据一并保存在记录与 CSV 导出中。

当前国服读取配置：`16.20.824.8524`。

## 下载与安装

1. 在本页 **Assets（资源）** 中下载唯一的安装包 **RiftCast-1.1.5-Setup-x64.exe**。
2. 如果正在使用旧版，请先退出 RiftCast。
3. 双击安装包，按提示选择安装目录并完成安装。
4. 从桌面或开始菜单打开 **RiftCast 导播**，连接国服观战或回放。

选手画面需要轮播时，点击“5 秒自动轮播”或“恢复 5 秒轮播”，在预监确认后点击“切入节目”。勾选“保持当前对位”可暂停画面轮换。
