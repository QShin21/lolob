# RiftCast 0.9.1

## 更新内容

- 首发对位仅显示基石符文与副系，隐藏主系和其余符文，无缺失占位。
- 右队符文靠右排列，图标顺序与左队镜像。
- 修正上单、中单、下路图标：分别突出左上路径、对角路径、右下路径。
- 新增 173 位英雄的专用横幅图库，每张固定为 1200×312。使用官方横向原画，根据英雄分别保存裁切位置，避免竖版卡片再次裁切导致脸部缺失。图片随包提供，可离线展示。
- 保留 0.9.0 的经济识别修复、经济与 ID 同字号、装备按价值从中央向外递减排列。

## 安装

下载 Setup-x64.exe 安装，或解压 Windows-x64.zip 运行 RiftCast.exe。更新保留赛事、设置与历史记录。

## 图库维护

裁切配置为 shared/lineup-banner-crops.json；运行 node scripts/prepare-lineup-banners.mjs 可从缓存或官方原画重新生成 public/lineup-banners，输出清单记录来源、裁切矩形和 SHA-256。首发对位直接展示生成后的横幅，运行时不再二次裁切。

## 验证

自动测试、镜像排布与符文数量检查、全图库尺寸与完整性检查，以及 Windows 独立目录运行检查。本版本未进行实际推流测试。
