# RiftCast 1.2.0

单人导播现在可以在工作台右侧“回放”栏直接控制当前游戏回放。

- 新增英雄击杀、中立资源与团战事件列表，可按类型、选手和时间搜索。
- 点击英雄击杀，优先回到本轮连续受伤起点前 3 秒；点击团战，回到首次伤害前 5 秒，并以正常速度播放。
- 团战识别要求同一连续交战链中双方各至少两人、合计至少五人。连续 8 秒无伤害后拆为下一段；分开的单挑独立识别。
- 提供播放/暂停、0.25～8 倍速、前后 10 秒、时间输入、进度拖动，以及返回首次跳转前位置。
- 回放栏可直接切入团战视图或返回局内计分板。游戏来源的跳转同步影响节目和预监，OBS 独立片段回放继续保留。
- 回看已结束对局时，局内节目跟随回放读数；已保存的赛后报告和结果保持独立。

## 数据范围

当前逐次伤害配置适配国服构建 16.20.824.8524。ROFL 回放提供整场英雄击杀与团战索引；实时观战使用已采集的伤害分片，跳转范围受游戏自身缓冲限制。

中立资源优先读取游戏事件，接口缺失时，通过连续播放中的直接资源计数变化补充。未采集过的历史资源事件暂不补造；缺少可靠伤害起点的事件标注为“事件前 3 秒（伤害起点待确认）”。回放事件列表只用于控制台，不注入节目统计。

## 使用方法

1. 打开国服观战或回放，等待 RiftCast 的游戏数据与回放接口连接。
2. 在导播台右侧选择“回放”，查看“游戏回放 · 事件导航”。点击事件即可跳转；也可输入 `12:30` 或秒数并点击“跳转”。
3. 需要十人团战面板时点击“切入团战视图”，结束后点击“返回局内计分板”。镜头位置仍使用游戏当前镜头设置。

## 下载安装

展开本页 **Assets**，下载唯一安装包 **RiftCast-1.2.0-Setup-x64.exe**。退出旧版 RiftCast 后，双击安装包，按向导安装；升级可沿用原安装位置。完成后从桌面或开始菜单启动 **RiftCast**。
