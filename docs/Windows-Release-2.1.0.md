# 观澜 2.1.0 ·「墨与信号」界面重做

观澜 2.1.0 把导播工作台的全部界面重做了一遍：外壳、导播台、六个工作页面、手机席位和各对话框换用同一套新的设计系统，品牌标志与安装程序美术同步更新。功能、快捷键、数据与存档格式沿用 2.0.0，升级后继续使用原有赛事资料与输出配置。节目输出与 2.0.0 逐像素一致。内置节目风格恢复为 1.7.1 的六套。

## 导播工作台

- **新设计系统「墨与信号」。** 界面骨架只用墨与纸两种无彩色，面板靠明度分层，去掉了层层描边与卡片嵌套。色相只留给信号：朱砂红是正在播出（PGM），石绿是预监与就绪（PVW），琥珀是待处理，蓝与红是两支队伍。主按钮、选中与焦点用明度表达。
- **深色「墨」与浅色「素」两套主题。** 在「连接与输出 → 工作台外观」或导航栏底部切换，正文对比度均不低于 4.5:1，节目输出不受主题影响。
- **字体。** 页面与对话框标题用思源宋体，界面文字用 IBM Plex Sans 配思源黑体，计时、电平和快捷键等读数用 IBM Plex Mono。五套字体随应用离线提供，不同电脑上的中文显示一致。
- **导播台。** PGM 与 PVW 监视器放大，画面带 2px Tally 色框；场景库卡片在 PVW 时显示石绿框，在 PGM 时显示朱砂框；右侧临场工作区的混音台、回放、字幕等任务统一了版式。
- **全部页面。** BP 与阵容、实时数据、赛事与素材、连接与输出、赛后收尾、使用指南、手机席位，以及场景编辑器、风格包、本局资料等对话框按同一套组件重做，统一了页签、列表、表单、空状态和选中、悬停、焦点状态。

设计规范见 [观澜 2.1 设计系统](Design-System-2.1.md)。

## 操作位置的变化

功能与流程不变，下列控件换了位置：

| 控件 | 2.0.0 | 2.1.0 |
| --- | --- | --- |
| 切入节目（TAKE） | 导播台在监视器下方，其他页面在底部 | 所有页面都在底部播出条右端 |
| 下一次切入、待播变化 | 导播台监视器下方 | 底部播出条，紧邻切入节目；点击“N 类待播变化”查看明细 |
| 节目回执、节目版本 | 导播台监视器下方 | 底部播出条左端，PGM 场景名下方 |
| 页面标题 | 各页面左上角 | 顶栏左侧 |
| 当前比赛比分 | 顶栏中部 | 顶栏中部，点击打开赛事资料 |

快捷键不变，切入节目仍为 `Ctrl+Enter`。

## 品牌与安装

- 新标志是一枚朱砂圆点悬在两道水纹之上：水面上的日出，也是信号上方的播出指示灯。
- 应用图标、浏览器标签图标、安装向导侧栏与页眉、启动画面同步更新。

## 节目包装

- 内置风格恢复为六套：青花瓷 · 云山雅韵（默认）、冰川极光、曜金典藏、霓虹脉冲、朱砂墨韵、瓷白竞速。2.0.0 加入的「裂隙曜金」不再内置。
- 在 2.0.0 选用过裂隙曜金的工作站，升级后预监、节目与撤回快照会回退到青花瓷 · 云山雅韵，风格包窗口会给出提示，其余资料不变。需要继续使用时，请在升级前从 2.0.0 的风格包窗口导出 ZIP，升级后作为自定义风格导入。
- 六套内置风格与已导入的自定义风格保持原内容指纹，节目画面与 2.0.0 逐像素一致。

## 升级说明

请先停止推流、录制和节目输出。1.6.0 及以后的安装版可在应用内点击「检查更新」升级。手动升级时，退出旧版后运行本页安装包并沿用原安装目录。升级后继续使用 `%APPDATA%\RiftCast` 中的用户数据。

操作步骤见 [观澜 2.1.0 PDF 用户手册](user-manual-2.1.0/观澜-2.1.0-用户使用手册.pdf)。本版手册以 2.0.0 手册为基础，按新界面重新截取工作台截图，修订了界面总览、切入节目的位置和风格包清单；其余章节的操作说明沿用前版。

## 兼容性与验证范围

- 游戏版本适配与 1.7.1 相同（国服 `16.23.840.6595` 观战遥测与逐次伤害）。
- 服务端接口、状态文件、风格包格式 v1、协作协议未变。
- 节目输出：六套内置风格 × 十一个场景以及分析、团战、赛后各页共 87 幅输出画面，与 2.0.0 逐像素、逐元素样式比对一致。
- 界面校验（工作台布局与键盘流程、主题与节目色彩隔离、制作流程与权限）和服务端测试在本版源码通过；安装包在 Windows x64 环境构建并校验哈希。真实 OBS、推流、音频设备和真实对局沿用 1.7.1 的现场验证结论，本版未改动这些链路。
