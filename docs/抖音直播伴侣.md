# 抖音直播伴侣：完整节目音画

适用 RiftCast 0.7.0。账号已具备直播伴侣开播权限后，画面走 OBS Virtual Camera，声音走基础版 VB-CABLE 虚拟麦克风。

## 首次准备与每场开播

1. 在「连接与输出 → 输出」选择「抖音 · 直播伴侣」，点击 **自动准备完整音画**。已有有效摄像头注册和音频驱动会直接复用。
2. 缺少组件时 OB 调用随包官方安装程序，校验文件哈希和 Windows 数字签名。首次安装接受管理员授权，并按官方要求重启电脑，重新打开 OB 与伴侣。
3. 核对正式节目、游戏声和解说，点击 **启动伴侣音画**。
4. 伴侣摄像头选择 **OBS Virtual Camera**；麦克风选择 **CABLE Output (VB-Audio Virtual Cable)**，音量 100%，关闭额外系统声音、原麦克风和降噪 / 自动增益。
5. 游戏、解说、采访、回放、音乐的音量、静音和同步在 OB 调整。伴侣预览试听、核对口型后点击伴侣的「开始直播」。
6. 收尾先在伴侣结束直播，再按住停止 OB 伴侣音画及本机录制。

OB 从 OBS 节目音轨 1 读取最终混音，按 48 kHz 双声道送入 CABLE Input，伴侣从 CABLE Output 接收声音。OB 识别基础版双声道端点，排除 Pack45 的额外 16ch 播放端点；固定原游戏输出和真实麦克风，检查反馈路径，并管理监听与音轨。安装若切换默认音频设备，OB 尝试恢复安装前各角色的原设备。

伴侣中的摄像头、麦克风选择和账号开播由操作者完成。OB 未写入伴侣私有配置，也未自动操作账号开播。

## 音乐与回放

导播台「音频」可添加 32 MB 以内的 MP3、WAV、OGG、FLAC。添加和更换在停播窗口进行；添加后默认暂停、静音，新音乐通道默认 -18 dB。点击播放后加入游戏、自定义正式场景、回放和备用场景，可在音乐通道调整音量及同步。重启后保留文件并暂停。

回放「原声」使用片段声音，临时静音现场游戏与解说；「新解说」关闭片段原声并使用现场解说。音乐继续参加节目混音。返回比赛恢复切入前的游戏、解说静音状态。

最终混音取自 Program。待播声音不会因预监而自动送入伴侣。送出期间 OB 管理监听，原「仅监听」来源继续排除播出；停止后恢复原监听、录制音轨以及 Windows 线缆端点的音量和静音。异常退出留下的恢复记录会在下次内置 OBS 启动时处理。

## 排查

- **驱动已安装但没有虚拟麦克风**：先重启 Windows，在本机桌面启动 OB 并刷新。远程桌面可能只暴露「远程音频」，程序会保持未就绪。
- **声音重复或回声**：伴侣只保留 CABLE Output 一路麦克风，关闭额外系统声与原麦克风。OB 游戏和解说应采集原设备。
- **音乐无声**：添加后默认暂停和静音，点击播放，再展开音乐通道检查音量。
- **回放无声**：核对原声 / 新解说策略、片段录制音轨、音乐及解说电平。
- **音画不同步**：在伴侣预览核对口型，通过 OB 各通道同步偏移调整，并检查伴侣音频处理。
