# RiftCast 0.9.0

## 本次更新

- 修复全新安装、迁移不完整或断网时，个人 OCR 因缺少 champions.json 和英雄头像而无法匹配选手的问题。直接使用随安装包提供的英雄目录和图标，按需生成 PNG 识别模板；损坏缓存自动重建，部分失败保留已可用模板并重试。构建时检查所有内置英雄图标。
- 局内个人经济 `余额(累计经济)` 与选手 ID 使用相同字号，重新分配行内宽度。
- 两队装备按目录总购买价格从计分板中央向外递减排列；同价保留原顺序，未知价格在已知价格之后，空位排到最外侧。饰品独立显示，叠加数量跟随原装备。
- 赛后经济面板明确显示已冻结、停止连续采样，并提示进入下一局或建立新系列赛，避免把历史读数当作新采样。
- 首发对位采用参考图结构：浅色背景，顶部队名/队标/系列赛比分与 GAME 局号，下方五行左右镜像英雄横幅，中央分路图标，选手 ID 下排列实际可用的符文图标（最多六枚）。
- 当前 Live Client API 能提供十位选手的基石、主系及副系；当前回放未提供十人的完整六枚符文。仅在 API 提供完整页且身份匹配时显示六枚；其余仅显示 API 返回的基石、主系和副系，不设置缺失占位。主副系图标保留原本含义，当前玩家的完整页也不会复制给其他选手。符文图标随包提供。

## 使用

下载 Setup-x64.exe 双击安装，或解压 Windows-x64.zip 后运行 RiftCast.exe。用户赛事与历史记录保留。展开原生底部经济计分板、确认局内 API 与游戏捕获已连接；屏幕回退采样时保持游戏窗口可见。赛后记录锁定期间，如需测试其他录像，请建立新的系列赛。

装备价格来自对应版本装备目录；目录暂不可用时保留非空装备的原顺序。首发图中的队伍名称、队标和比分使用当前赛事资料。

## 验证范围

319 项自动测试通过，并覆盖空数据目录、断网头像生成、损坏缓存修复、实际 Windows OCR 十选手原图、装备排序和叠加数量、字号一致、首发五行镜像布局、完整符文页及部分 API 内容无占位显示、选手身份隔离及赛后冻结提示。Windows 安装包及独立目录运行另行核验。

此前本机回放连续采样已确认补齐资源后恢复十人识别；本版本的全新安装路径使用空目录及原图验证。API 缺失的完整符文仍保持不可用，不根据英雄常用配置补造。
