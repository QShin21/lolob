# RiftCast 1.0.2

风格包管理新增删除功能。选择一个闲置风格版本，点击“删除风格包”，核对名称、版本和修订号后确认；也可取消。删除自定义版本会移除其本地清单和贴图，同名其他修订继续保留。删除结果在重启及升级后保留，可重新导入原 ZIP 恢复。

非默认内置风格也可从管理列表删除，原始素材保留在安装目录；重新导入随 Release 提供的对应风格 ZIP 即可恢复。默认“冰川极光”用于安全回退，保留在列表。待播配置、当前节目及撤回快照正在引用的版本会显示具体原因并阻止删除。只有当前主导播可导入、删除和切换风格。

Windows x64 请下载 `RiftCast-1.0.2-Setup-x64.exe` 安装，或解压 `RiftCast-1.0.2-Windows-x64.zip` 后双击 `RiftCast.exe`。保留 ZIP 中所有文件。更新前退出运行中的应用，原有赛事数据沿用。

发布验证包括 Windows 单元测试、类型检查、生产构建、内置素材与区域契约、11 场景预览、五套内置风格，以及隔离目录的打包 EXE。删除功能覆盖确认、取消、权限、使用保护、文件移除、重启及重新导入。验证结果随 Release 提供。真实游戏、OBS 推流及平台观众端效果仍需播出环境验收。
