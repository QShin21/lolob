## 从任务重新组织界面

main 的导播台依次放置品牌侧栏、面包屑、页头、流程条、播出条、比赛条、阶段条，再放监视与任务，场景库排在其后。它让关键操作争夺高度。本轮将结构改成：

- 68px 导航轨保留七个深链接；52px 顶栏显示本版节目比赛身份与同步状态。
- 紧凑常驻播出带显示 PGM/PVW、待播差异、引擎应用、四条独立输出状态和应急操作。
- 导播台左侧两台等宽 16:9 监视器，下方唯一主 TAKE 操作和可滚动场景库；右侧是独立滚动的临场任务。低频本局资料用真实模态窗口打开，释放原生监视。
- 自定义场景改为左图层、中画布、右属性；画布点选、拖移、八向缩放、方向键微调都只更新本地草稿。来源选择收在图层栏，精确数值始终保留。
- 输出区把 Program 的视频与最终混音分别画出路径；设备准备、活动输出、人工核对分开。混音台先呈现通道条，再呈现单来源音乐控制。

这次“旧版”只指上述 main 基线。实现差异必须通过同尺寸的新截图和实际操作核对，不能用代码行数证明。
