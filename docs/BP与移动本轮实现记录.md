## 输入与设计决定

已完整阅读 `前端设计实施方案.md`、官方 frontend-design 技能，以及 Library 任务书 `libfile_fa8f64dc18bc8191840dd744c317798c` 的 1–125、126–248、249–371、372–493 行（493 行、58822 字节）。本记录只覆盖本轮 BP 与移动协作切片，不将其他页面或历史验收计入完成。

使用整合者提供的六色基础变量：`#11151B` 页面、`#181E26` 工作面、`#222A34` 控件、`#EFF3F7` 正文、`#ADB8C7` 次文字、`#70D7C2` 品牌；亮色沿共享 `--ui-*` 变量。中文和英文使用本地 Segoe UI / Microsoft YaHei / PingFang SC；正文 14px、辅助 12px、领域标题 20px，局号与倒计时等宽数字。蓝红表示阵营，PGM/PVW 独立表示播出身份。

BP 以当前回合和两队选择顺序形成一张连续工作面。选人行同时显示槽位、英雄状态与已保存归属；禁用为紧凑横排。当前槽位、预选、已选和归属锁定使用不同文字。低频同步、回退、规则与历史在下方任务区；英雄搜索使用原生侧面 dialog，明确保存目标与待播影响，关闭回到原槽位。

```text
当前队伍 / 当前动作 / 秒数       当前模式 / 接管与差异
蓝队 / 选择顺序 / 已确认归属     红队 / 选择顺序 / 已确认归属
B1…B5 英雄与选手                R1…R5 英雄与选手
本局五个禁用                    本局五个禁用
归属核对 | 客户端同步 | 规则与历史       BP 排版核对
```

移动首屏在一条身份栏说明席位、本人及同步，再给出当前节目控制者、一台 PGM/PVW 可切换监视器和角色任务。资料席的场景为可搜索列表，含已有动态自定义场景；字幕、回放等沿真实制作组件。只有当前持有控制权的主导播显示底部 TAKE；其余席位明确说明执行者。底部动作采用粘性区域并留安全区，窄屏不固定遮盖表单。

自审修订：原始“规则接管大面板 + 五个英雄小卡片 + 底部英雄网格”重复标题且不突出当下动作；改为双队连续行与真正侧面弹窗。移动复制桌面全任务并常驻灰色 TAKE 不能解释权限，改为当前席位的任务面及具体执行者。无需新的装饰字体、渐变、营销副标题或业务虚构。

## 保护边界

- 只修改 Draft、Remote 与本域组件/样式，保留后端、Program 快照、BroadcastCanvas 和 ProductionDesk 接口。
- `set-draft`、`production`、`preview-scene`、`take` 继续经原真实 API；归属、英雄选择与规则保存保留配置版本及拒绝后的本地输入。
- 席位角色不等于节目控制权。远端不增加来源枚举、设备配置、主机捕获或层编辑权限。
- 历史按系列、局号与双方稳定战队 ID 过滤；换边后按同一战队 ID 读取英雄，不能默认取红方历史。
- 不启动 OBS、推流、设备、驱动，不更动真实 data/runtime，不提交或推送。

## 本轮实现与验证

### 已实现

- BP 主工作面重写为当前回合与双队连续槽位。每行区分选择顺序、已选/待处理、选手与分路；本局禁用和客户端预选分开显示。归属统计只计仍属于本队已选英雄及当前名单的确认项。
- `DraftChampionPicker` 使用原生 modal dialog，侧面排列；自动聚焦搜索、Escape 关闭、关闭返回触发槽位，键盘事件不会冒泡为播控快捷键。候选直接说明前局禁选、本局占用、历史局号与当前选择；点击候选仍属本地选择，经“保存此槽位到待播”调用真实 `set-draft`。
- 英雄面板在待播版本、客户端选择/禁用或比赛身份改变时保留所选英雄，先显示重新核对提示；错误留在面板中。只改目标槽位，遵循服务端现有人工接管语义。
- 归属、客户端同步、规则拆为 `DraftAssignments`、`DraftSyncControls`、`DraftRuleControls`，由薄任务外壳组织。未保存归属、规则和理由在切换任务时保留；交换或改英雄/分路会取消相应归属锁定。保存、放弃及冲突核对是独立动作。
- 客户端对照覆盖双方五个选择及五个禁用，列出样本时间和未锁定预选。恢复同步前明确确认替换 BP 与名单；倒计时变化不会反复清除核对，英雄、禁用或名单变化会要求重新核对。人工接管、差异模式、理由回退、理由清空保留真实 API。
- 规则使用本地表单后明确保存，支持普通 BP、双方/本队禁选、裁判例外局与重赛历史。GAME 5 只按真实例外局配置放开。历史按当前系列和双方稳定 ID 筛选，再分别映射当前两队，不再将不匹配身份默认算成红方；前局历史区受控滚动。
- Remote 重写为席位/本人/同步、当前控制者、比赛身份、一台 PGM/PVW 监视器与角色任务。资料与导播席的预监列表支持搜索、已有自定义场景和 PGM/PVW 独立标识；不枚举或编辑主机来源。
- Remote 只有 `director` 且 `control.owner === seat.id` 时显示底部 TAKE。其他席位明确说明执行者；另一个主导播角色不会被当作持有控制权。未验证席位不挂载制作任务；断线禁用提交但保留已挂载任务草稿。
- 主机沿 `MonitorPane` 的实际合成/快照能力；局域网地址显示明确标注的节目/待播排版示意，不冒充可访问的 OBS 合成。节目排版使用 `programState` 与已播自定义快照，预监使用待播状态。切换监视器不会卸载制作任务。
- 收到已失效席位等真实错误后，Remote 保留提示并停止提交，未自行重新签发席位或变更权限。提交错误不藏在固定底栏下；底栏为 sticky，并考虑底部安全区和小高度横屏。
