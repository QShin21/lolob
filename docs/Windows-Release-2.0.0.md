# RiftCast 2.0.0 ·「演播室暗场」视觉全面升级

2.0.0 重做了 RiftCast 的全部视觉：导播工作台、品牌标志与应用图标、安装程序、启动画面，并新增一套旗舰节目风格包。功能、操作流程、快捷键、数据与存档格式沿用 1.7.1，升级后原有赛事资料、风格选择和输出配置保持不变。

## 导播工作台

- **新设计系统「演播室暗场」。** 深曜石蓝四级表面、弧光青交互色、黄铜金品牌色。红色只表示 PGM，绿色只表示 PVW，监视器、场景库和底部安全带的播出状态一眼可辨。
- **浅色主题「日光」同步重做。** 两套主题的正文对比度均不低于 4.5:1，在「连接与输出 → 工作台外观」切换，节目输出不受影响。
- **导播台。** PGM／PVW 监视器带 Tally 色描边与标题条；切入节目（TAKE）是界面里唯一的红色实底大按钮；场景库卡片显示所在总线；顶栏比分牌按蓝红方身份着色。
- **全部二级页面。** BP 与阵容、实时数据、赛事与素材、连接与输出、赛后收尾、使用指南、手机协作台以及各对话框统一了标题层级、表格节奏、空状态和选中、悬停、焦点状态。
- **字体。** 界面使用 Inter，数字与标签使用 Barlow Condensed，随应用离线提供；中文使用系统字体。

设计规范见 [RiftCast 2.0 设计系统](Design-System-2.0.md)。

## 品牌与安装

- 新标志：黄铜金 R、弧光裂隙与红色播出指示灯。
- 应用图标提供 16 至 256 像素共 9 个尺寸，任务栏、桌面快捷方式和安装程序均清晰显示。
- 安装向导使用新的侧栏与页眉图。
- 启动与重连画面、浏览器标签图标、团队画面页面同步更新。

## 节目包装

- 新增第七套内置风格 **裂隙曜金**（`rift-signature`）：曜石蓝底、黄铜金线框与一道弧光裂隙，四张全幅背景各有独立构图，与工作台同一视觉语言。在「场景库 → 风格包」选择，准备到预监后 TAKE。
- 原有六套内置风格及已导入的自定义风格保持原内容指纹；默认风格仍为青花瓷 · 云山雅韵。

## 升级说明

安装前请先停止推流和录制，再退出旧版。运行 `RiftCast-2.0.0-Setup-x64.exe` 覆盖安装，数据目录 `%APPDATA%\RiftCast` 继续使用。1.6.0 及以上版本可在应用内「检查更新」直接升级。

操作步骤见 [2.0.0 PDF 用户手册](user-manual-2.0.0/RiftCast-2.0.0-用户使用手册.pdf)。本版手册沿用 1.7.0 的章节与操作说明，新增工作台视觉变化和裂隙曜金的使用说明及节目示例。工作台截图按 2.0.0 重新截取，历史节目、桌面端更新弹窗及需真实 OBS 的协作图沿用前版，手册内已注明。

## 兼容性与验证范围

- 游戏版本适配与 1.7.1 相同（国服 `16.23.840.6595` 观战遥测与逐次伤害）。
- 服务端接口、状态文件、风格包格式 v1、协作协议未变。
- 界面校验（14 项工作台检查、8 项主题检查、节目色彩隔离）与服务端测试在本版源码通过；安装包由 GitHub Actions 的 Windows 环境构建并校验哈希。真实 OBS、推流、音频设备和真实对局沿用 1.7.1 的现场验证结论，本版未改动这些链路。
