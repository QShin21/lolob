# 观澜 2.0.0 · 演播室暗场视觉全面升级

观澜 2.0.0 更新了导播工作台、品牌与应用图标、安装程序和启动画面，并新增一套旗舰节目风格包。功能、操作流程、快捷键、数据与存档格式沿用 1.7.1，升级后继续使用原有赛事资料、风格选择和输出配置。

## 更名说明

RiftCast 更名为观澜，拉丁字标为 **GUANLAN**。桌面和开始菜单的快捷方式名为「观澜导播」。

Release 的唯一 EXE 安装资产沿用文件名 `RiftCast-2.0.0-Setup-x64.exe`，供 1.6.0–1.7.1 客户端识别和下载。安装后保留 `RiftCast.exe`，旧版更新器可从原路径重新启动。便携版文件名为 `GuanLan-2.0.0-Windows-x64.zip`。

## 导播工作台

- **新设计系统「演播室暗场」。** 深曜石蓝四级表面、弧光青交互色、黄铜金品牌色。红色只表示 PGM，绿色只表示 PVW，监视器、场景库和底部安全带的播出状态一眼可辨。
- **浅色主题「日光」同步重做。** 两套主题的正文对比度均不低于 4.5:1，在「连接与输出 → 工作台外观」切换，节目输出不受影响。
- **导播台。** PGM／PVW 监视器带 Tally 色描边与标题条；切入节目（TAKE）是界面里唯一的红色实底大按钮；场景库卡片显示所在总线；顶栏比分牌按蓝红方身份着色。
- **全部二级页面。** BP 与阵容、实时数据、赛事与素材、连接与输出、赛后收尾、使用指南、手机协作台以及各对话框统一了标题层级、表格节奏、空状态和选中、悬停、焦点状态。
- **字体。** 界面使用 Inter，数字与标签使用 Barlow Condensed，随应用离线提供；中文使用系统字体。

设计规范见 [观澜 2.0 设计系统](Design-System-2.0.md)。

## 品牌与安装

- 工作台顶栏并排显示「观澜」与 GUANLAN。启动与重连画面、手机协作、浏览器标签和团队画面同步使用观澜名称。
- 新标志画的是峡谷地图：三条黄铜金兵线、蓝红两座基地、一道弧光河道（澜），河道与中路交汇处是导播镜头（观）。
- 应用图标提供 16 至 256 像素共 9 个尺寸，供任务栏、桌面快捷方式和安装程序使用。
- 安装向导使用新的侧栏与页眉图。

## 节目包装

- 新增第七套内置风格 **裂隙曜金**（`rift-signature`）：曜石蓝底、黄铜金线框与一道弧光裂隙，四张全幅背景各有独立构图，与工作台同一视觉语言。在「场景库 → 风格包」选择，准备到预监后 TAKE。
- 原有六套内置风格及已导入的自定义风格保持原内容指纹；默认风格仍为青花瓷 · 云山雅韵。

## 升级说明

请先停止推流、录制和节目输出。1.6.0–1.7.1 安装版可在应用内点击「检查更新」升级。手动升级时，退出旧版后运行本页安装包并沿用原安装目录。升级后继续使用 `%APPDATA%\RiftCast` 中的用户数据。

操作步骤见 [观澜 2.0.0 PDF 用户手册](user-manual-2.0.0/观澜-2.0.0-用户使用手册.pdf)。本版手册沿用 1.7.0 的章节与操作说明，新增工作台视觉变化和裂隙曜金的使用说明及节目示例。工作台截图按 2.0.0 重新截取，历史节目、桌面端更新弹窗及需真实 OBS 的协作图沿用前版，手册内已标明出处和曾用名称。

## 兼容性与验证范围

- 游戏版本适配与 1.7.1 相同（国服 `16.23.840.6595` 观战遥测与逐次伤害）。
- 服务端接口、状态文件、风格包格式 v1、协作协议未变。
- 界面校验（14 项工作台检查、8 项主题检查、节目色彩隔离）与服务端测试在本版源码通过；安装包在 Windows x64 环境构建并校验哈希。真实 OBS、推流、音频设备和真实对局沿用 1.7.1 的现场验证结论，本版未改动这些链路。
