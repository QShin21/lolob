# RiftCast 1.0.4

- BP 英雄卡仅保留选手 ID，删除选取编号、分路、英雄名、锁定提示与两侧队名横栏；队名、队标和系列比分集中于中间栏目。
- 左右禁用栏逐局纵向堆叠，历史局展示该队已选英雄，最下方 GAME 显示本局 Ban。换边后继续按队伍身份对应历史。
- 局内底部计分板增高 20%，文字、英雄与技能图标随之调整；装备分两行排列，摄像头与 OBS 合成坐标同步适配。
- 青花瓷 · 云山雅韵作为第六套内置风格和新安装默认风格；保留已保存的风格选择。所有内置风格和已导入风格共用新版 BP 与计分板布局。
- 赛后对位经济改为双方总和占比条形图；分段间隙保持原宽度，经济数字维持中央固定对齐。缺失数据或双方均为零时保留中性底条。
- Windows 安装器、便携 ZIP、六套可导出的风格包与校验清单随版本发布。

验证包含服务端测试、构建、六套风格的浏览器布局与导入恢复、Windows 打包程序检查。合成数据预览不代表真实对局、OBS 推流或观众端验收。
