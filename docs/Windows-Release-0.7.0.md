# RiftCast 0.7.0 Windows Release

2026-10-13。本版把游戏、解说、回放、采访和音乐的完整节目混音接到抖音直播伴侣，并保留 0.6.0 的虚拟摄像头、自定义场景和原生预览。

## 安装与开播

安装版运行 RiftCast-0.7.0-Setup-x64.exe；免安装版完整解压 RiftCast-0.7.0-Windows-x64.zip 后运行 RiftCast.exe。无需另装 Node.js、Electron 或 OBS。更新前退出旧版。

1. 在「连接与输出 → 输出」选择「抖音 · 直播伴侣」，点击 **自动准备完整音画**。
2. 首次安装接受 Windows 管理员授权，按官方要求重启 Windows，再打开 RiftCast 和直播伴侣。已有有效组件会直接复用。
3. 核对正式节目，点击 **启动伴侣音画**。OB 会启动虚拟摄像头和完整混音，音频启动失败会拒绝启动本次画面输出。
4. 伴侣摄像头选择 **OBS Virtual Camera**；麦克风选择 **CABLE Output (VB-Audio Virtual Cable)**，音量 100%。关闭伴侣额外的系统声音、原麦克风及降噪 / 自动增益。
5. 在伴侣预览核对画面、电平和口型，再点击伴侣「开始直播」。收尾先在伴侣结束直播，再按住停止 OB 伴侣音画。本机录制可以独立启停。

OB 自动识别基础版 VB-CABLE 的双声道端点，从节目音轨 1 取得最终混音，并管理音轨、监听、真实采集设备固定和防反馈检查。伴侣中的摄像头、麦克风选择和账号开播由操作者完成。

## 音乐与回放

导播台「音频」可添加 32 MB 以内的 MP3、WAV、OGG 或 FLAC。添加后默认暂停、静音，新通道默认 -18 dB。点击播放后进入节目混音，可暂停、停止，也可展开音乐通道调整音量、静音和同步。更换文件要求先停止伴侣输出、RTMP 和录制。

音乐会加入游戏、自定义正式场景和回放场景，预监场景不额外加入音乐。重启后保留音乐并暂停，输出由导播手动启动。

回放沿用 OB 策略：**原声**播放片段声音，临时关闭现场游戏和解说；**新解说**关闭片段原声并使用现场解说。音乐继续参与节目混音。返回比赛会恢复切入前的游戏、解说静音状态。

## 状态与恢复

软件显示虚拟麦克风名称、混音运行状态和电平，输出格式为 48 kHz 双声道。设备丢失或音频线程失败会显示异常。送出期间仍可调整各通道音量、静音和同步，监听与录制音轨由 OB 保护。原「仅监听」来源继续排除播出。

停止后恢复原监听、音轨及 Windows 虚拟音频端点的音量、静音。异常退出留下的路由恢复记录在下次内置 OBS 启动时处理。安装若切换默认设备，OB 尝试恢复安装前各角色的原设备。

避免把 VB-CABLE 设为 Windows 默认扬声器或麦克风，OB 也应采集原设备。远程桌面可能只显示「远程音频」；当前会话看不到 CABLE 端点时会保持未就绪，请在本机桌面使用并刷新。

## 数据、许可与验证

赛事、素材、音乐、视频和独立 OBS 配置保存在 %APPDATA%\RiftCast。更新和卸载保留用户数据。安装包不包含本机赛事、视频、推流码、OBS 密码或个人配置，旧 0.6.0 release 原样保留。

应用内置官方 OBS Studio 32.2.2、音频桥接库、设备工具及未经修改的官方基础版 VB-CABLE Pack45 安装包。节目音频组件源码、OBS 对应源码、GPL 文本和第三方声明随包提供。

VB-CABLE 来自 [VB-Audio Software](https://vb-audio.com/Cable/)，采用 donationware 模式。欢迎参与捐赠；专业使用和批量分发按 [官方许可](https://vb-audio.com/Services/licensing.htm) 支付相应许可。基础版随包提供，未分发 A+B、C+D。

构建入口 npm run release:win，新产物在 release/0.7.0。同目录 SHA256SUMS.txt 和 release-manifest.json 保存产物、源码哈希及版本信息。

本机验证使用生成的测试音视频，核对虚拟设备收发、混音、音量、静音、预监隔离、回放策略及停止行为。实际游戏、现场麦克风、伴侣开播和抖音观众端音画同步仍需目标环境验收。应用尚未配置 Windows 商业代码签名证书。
