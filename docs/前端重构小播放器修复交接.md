## 这次实际改了什么

live 仍是原有五行和镜像六组信息。姓名独占上行，大招状态移至其下方，与生命/资源/经验条同行；装备区略收窄，把内部空间让给姓名和数字。没有删除装备、符文、召唤师技能、大招状态或统计；没有更改数据格式、快照、OCR、OBS、摄像头或遮挡参数。长名继续省略，不用无限缩字；KDA 保留完整斜线格式。变化发生在 `LiveBottom.tsx` 与其原样式声明内。

BP 的选择序号与状态现在放在同一条顶部标签区，状态提高到 24px（1080p 基准）。已锁定、预选、选择中、待选分别显示，预选/选择中用高对比底色。长句“预选 · 未锁定”以“预选”短标呈现，完整未锁定语义仍保留在辅助标签、英雄名和队伍预选条中。没有改变 picks、preselect、归属或选人状态的判定。

历史区将原来的留白分给局号和归档状态，固定为 5.85cqw 高；最多四局和两侧稳定队伍归属保持。待进行的局号不再整体降透明，只有英雄占位降低透明。当前选人卡片大小、位置不变，历史区比原版略收紧，没有向游戏区域扩张。修改集中在 `PrematchScenes.tsx` 与 `program-scenes.css`，没有末尾覆盖样式。

## 两个 Windows 脚本的维护范围

`scripts/verify-custom-scenes.mjs`：新建按钮改为“新建场景”，窗口来源通过“添加来源 → 应用窗口 → 刷新主机来源 → 选择已枚举窗口 → 添加窗口”；保存改为“保存到待播”。画布截图定位到实际编辑画布。已播场景的删除入口现在会打开引用说明，因此保留“禁止删除”断言于真正的“确认删除”按钮，并增加节目引用文字核对，然后取消提示。

`scripts/verify-release.mjs`：新建和保存入口同步；音乐通过“连接与输出 → 声音”进入，并将音乐控件限定在当前声音工作面，避免命中仍挂载的隐藏导播台。输出路径先查看，再按“设为下一次输出”配置，增加“仅查看不改引擎”的断言；录制按钮改为“开始/停止本机录制”，外观入口改为“工作台外观”，伴侣指引定位实际 Program 信号路径。

真实窗口像素、PGM/PVW、快照、保存、关闭窗口失败保护、删除保留素材、DLL/EXE、音乐暂停/播放、虚拟摄像头帧、音画失败、录制、退出提示、重启恢复等原有业务断言保留。没有在实现中为脚本添加旁路，也没有把真实 OBS 分支换成模拟。**本批只检查脚本语法与源码接线，两个 Windows 集成脚本没有执行。**
