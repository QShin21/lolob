# RiftCast 0.9.2

## 更新

- BP、首发对位、局内计分板统一使用实际字宽测量，固定单行高度，自动调整长 ID 字号与横向比例，完整呈现中文、英文、混合名称。
- 赛后报告第 1 页：胜负、时长、双方英雄伤害条、KDA、团队经济、防御塔、小龙、远古龙、大龙、峡谷先锋、虚空巢虫、双方禁用英雄、经济差曲线。
- 第 2 页：系列赛比分、五路对位、英雄原画、KDA、符文、装备，以及 DMG% 伤害占比、DT% 承伤占比、KP% 参团率。
- 两页采用浅色背景与蓝金配色。场景库与赛后报告提供分页按钮；选页准备预监，TAKE 后切入。
- 接入相同 gameId 的 LCU 赛后伤害与承伤统计，按同队唯一英雄匹配选手并保存至归档。远古龙与普通小龙分别统计。

## 使用

运行 Setup-x64.exe 安装，或完整解压 Windows-x64.zip 后双击 RiftCast.exe。用户数据继续保存在原有目录。

## 数据与验证边界

旧归档未保存的伤害、承伤和虚空巢虫等数据以 — 显示。伤害占比需要同队五人数据齐全；缺失数据不会显示为 0%。经济曲线使用已采集的累计经济，采样中断留空。LCU 数据需 gameId 与本局归档一致。

验证包括自动测试、1920×1080 / 1280×720 真实浏览器排版、16 字符极限姓名、双页完整/缺失统计，以及独立目录打包程序运行检查。未进行真实对局与实际推流测试。
