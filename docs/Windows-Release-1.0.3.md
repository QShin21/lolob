# RiftCast 1.0.3

此版本仅使用本机客户端实时数据，客户端 API 轮询默认 500 毫秒，可调整为 100–2000 毫秒。

## 更新内容

- 移除演示数据切换、播放/暂停、重置、空格快捷键，以及节目中的演示标签。
- 首次启动使用空白赛事和待机画面，等待客户端 BP、局内 API 或观战 OCR 样本。不会自动生成选手、战绩、经济、事件或赛程。
- 升级时清理旧演示对局、演示归档和演示节目缓存；保留用户修改的队伍、赛事、素材、连接设置及真实归档。
- 在“连接与输出 → 数据连接”调整客户端 API 轮询间隔。默认 500 毫秒，支持 100–2000 毫秒；保存后生效。已有有效值继续保留，旧的越界值收敛到新范围。接口响应时间仍会影响实际采样频率。
- 保留五套内置风格、赛后报告、OCR、实时采集、节目/预监隔离、导播协作与风格包管理。

## 安装与启动

下载 `RiftCast-1.0.3-Setup-x64.exe` 安装，或完整解压 `RiftCast-1.0.3-Windows-x64.zip` 后打开 `RiftCast.exe`。运行无需额外安装 Node.js、Electron 或 OBS。

启动英雄联盟客户端，在“连接与输出 → 数据连接”检查 League Client、Live Client Data 与 Replay API 的实际连接状态。未进入游戏时没有局内样本属于正常状态。先填写赛事资料，再核对预监，确认后执行 TAKE。

1.0.2 图文手册中的演示模式说明仅适用于历史版本。当前版本的启动状态和轮询设置以本说明及软件界面为准。

## 验证范围

发布流程执行类型检查、自动化回归、真实服务 HTTP/持久化验证、构建后前端检查、风格与赛后画面检查、Windows 安装包/ZIP 构建、隔离打包程序启动，以及远程附件 SHA-256 和大小核对。具体结果随 `verification.json` 与 Actions 记录发布。

测试样本位于开发验证文件，安装程序不包含这些样本，前端没有测试入口。真实英雄联盟对局、OBS 推流和观众端接收效果需在目标环境验收。
