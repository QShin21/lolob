# RiftCast 0.6.0 Windows Release

2026-10-13。本版新增抖音直播伴侣虚拟摄像头输出，包含当前工作区已有的自定义场景、原生预览修复和 Windows 桌面运行环境。

## 安装与启动

安装版：双击 **RiftCast-0.6.0-Setup-x64.exe**，安装后从桌面或开始菜单启动 **RiftCast 导播**。更新前退出旧导播窗口。

免安装版：完整解压 **RiftCast-0.6.0-Windows-x64.zip**，双击 RiftCast.exe。保留同目录的 resources 和运行库。无需另装 Node.js、npm、Electron 或 OBS。

应用内置官方 OBS Studio 32.2.2、虚拟摄像头组件、原生投影辅助程序、英雄素材以及对应 OBS 完整源码和许可证。运行环境从安装包准备，无需在线下载。

## 抖音开播

1. 登录具备开播权限的抖音直播伴侣。
2. 在 RiftCast「连接与输出 → 输出」选择「抖音 · 直播伴侣」。如提示缺少虚拟摄像头，点击安装并接受 Windows 管理员授权；系统自动重新加载内置引擎，随后重新打开伴侣。已有可用注册会直接复用。
3. 核对正式节目，点击「启动伴侣画面」。
4. 在伴侣添加素材 → 摄像头 → **OBS Virtual Camera**，按横屏画布适配节目。
5. 在伴侣选择游戏系统声音和解说麦克风，试听、核对同步后点击伴侣的「开始直播」。
6. 场景切换继续在 RiftCast 操作。本机录制可以独立启动。收尾时先在伴侣结束直播，再停止画面输出和录制。

摄像头只发送画面；声音由伴侣直接采集。OBS 回放、媒体或音乐混音需要另接独立音频设备，并在伴侣选择对应输入。本版不自动安装虚拟音频驱动。回放画面可正常发送，回放声音需另行配置与实测。

完整指南见源码中的 docs/抖音直播伴侣.md。[抖音官方摄像头接入教程](https://streamingtool.douyin.com/docs/guide_yr6qkl09)。

## B站及 RTMP

在「连接与输出 → 输出」选择「RTMP · B站及其他推流平台」，应用本次接收地址和推流码，再返回导播台核对节目并开始推流。切换输出方式要求先停止已有直播输出和录制。

## 数据与版本

赛事、素材、缓存和独立 OBS 配置保存在 %APPDATA%\RiftCast。安装更新与卸载保留该目录，通用安装包与 ZIP 不包含本机赛事数据、录制视频、推流码、WebSocket 密码或个人配置。帮助菜单可打开数据目录与启动日志。

本版保存输出方式，重启后由导播手动启动画面发送。退出时，软件会核对推流、虚拟摄像头和录制状态。抖音直播间的开播、关播操作由伴侣完成。

旧版 0.5.0 安装产物保留在原 release 目录。构建入口为 npm run release:win，产物位于 release/0.6.0；验证入口为 npm run verify:release。构建记录保存基准提交、当前工作区状态、源码哈希、依赖版本和产物 SHA-256，同目录 SHA256SUMS.txt 用于核对完整性。

自动验证使用独立数据目录和 OBS 配置，覆盖打包程序启动、自定义场景、原生投影、虚拟摄像头实际启停、本机视频接收、输出状态与重启持久化。真实游戏、解说音频、直播伴侣开播和抖音观众端仍需目标环境验证。

应用尚未配置 Windows 商业代码签名证书。
