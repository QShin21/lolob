# RiftCast 1.2.1

修复回放事件重复，并让返回位置按正常时间持续推进。

- 游戏跳转后重复上报的击杀通知会合并为一条，兼容事件编号变化和小幅时间偏差。
- 在计算连续受伤段之前去重，保留“交战起点前 3 秒”的定位，消除同一次击杀后面的重复估算条目。
- 兼容选手完整 Riot ID 与击杀事件中的短名称。不同选手、后续真实击杀和独立资源击杀分别保留。
- “返回原进度”按正常 1 倍速持续更新时间：12:15 进入回放，经过 17 秒后显示并返回 12:32。回放中的暂停、倍速和再次跳转不会改变这条返回时间线；到达回放末尾后停止增加，返回后以正常速度播放。
- 新增重复通知、不同击杀保留及名称匹配的回归测试，并使用已保存的国服回放样本复核定位。

未获得可靠伤害起点的独立事件仍会显示估算标记；团战继续从首次伤害前 5 秒开始。

## 下载安装

展开本页 **Assets**，下载唯一安装包 **RiftCast-1.2.1-Setup-x64.exe**。退出旧版 RiftCast 后，双击安装包，按向导安装；升级可沿用原安装位置。完成后从桌面或开始菜单启动 **RiftCast**。

打开导播台右侧“回放”，游戏重新连接后会自动生成去重后的事件列表。
