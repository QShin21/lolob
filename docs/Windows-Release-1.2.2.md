# RiftCast 1.2.2

点击回放事件时，时间跳转与游戏镜头自动联动。

- 英雄击杀优先跟随击杀者；防御塔或野怪造成的击杀，在能够确认受害英雄时跟随该英雄。
- 团战优先跟随本段中的击杀者；尚无击杀时跟随率先参与交战的英雄。
- 中立资源事件能够确认击杀英雄时，也会跟随该选手。
- 事件列表显示跟随目标。游戏完成时间跳转后，切到目标单位并开启常规俯视镜头跟随。
- 镜头操作会读取游戏返回的选中单位进行确认。接口暂不可用或目标无法确认时，显示提示并保留已经完成的时间跳转。
- 保留 1.2.1 的事件去重和“返回原进度”动态计时。

已在国服回放中验证击杀、团战事件的跳转和目标单位选择。镜头使用游戏 Replay API，操作会同步影响当前游戏节目画面。

## 下载安装

展开本页 **Assets**，下载唯一安装包 **RiftCast-1.2.2-Setup-x64.exe**。退出旧版 RiftCast 后，双击安装包，按向导安装；升级可沿用原安装位置。完成后从桌面或开始菜单启动 **RiftCast**。

打开导播台右侧“回放”，点击事件即可跳转并切换镜头。事件下方可查看跟随目标，操作完成后面板会显示镜头结果。
