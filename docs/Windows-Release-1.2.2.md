# RiftCast 1.2.2

回放事件自动跟随击杀者，并修复来回跳转、暂停和倍速播放时的经济、补刀与伤害同步。

- 英雄击杀优先跟随击杀者；防御塔或野怪造成的击杀，在能够确认受害英雄时跟随该英雄。
- 团战优先跟随本段中的击杀者；尚无击杀时跟随率先参与交战的英雄。
- 中立资源事件能够确认击杀英雄时，也会跟随该选手。
- 事件列表显示跟随目标。游戏完成时间跳转后，切到目标单位并开启常规俯视镜头跟随。
- 镜头操作会读取游戏返回的选中单位进行确认。接口暂不可用或目标无法确认时，显示提示并保留已经完成的时间跳转。
- 保留 1.2.1 的事件去重和“返回原进度”动态计时。

- 回放操作会使正在读取的旧采样失效。每次采样核对读取前后的播放位置、速度和暂停状态，通过校验后整组更新选手数据。
- 检测游戏内直接跳转，拒绝跨时间点、跨对局或重连前的迟到响应；跳转加载期间暂时隐藏未同步的节目统计，收到对应画面的数据后自动恢复。
- 按游戏时间的 0.5 秒区间保存实际采到的十人状态、经济、补刀、伤害和资源状态，供本次运行中回看使用，最多保留 14,400 组。采样沿用设置中的轮询间隔；加速跳过的时间区间保留空缺。
- 经济曲线按当前游戏时间重建，回跳保留历史，返回后恢复已采到的曲线，避免混入未来数据。
- 已保存赛后报告的比赛仍可回看局内数据；回看过程保留赛后报告的原始终局记录。
- 跳转后团战伤害重新建立本段基准；伤害索引延迟加载时，从逐次伤害记录补回入口时刻的基准，恢复本段累计。

已在国服回放中验证事件镜头跟随、反复前后跳转、相同暂停时间点的十人读数一致，以及多档倍速采样。镜头和时间操作会同步影响当前游戏节目画面。

## 下载安装

展开本页 **Assets**，下载唯一安装包 **RiftCast-1.2.2-Setup-x64.exe**。退出旧版 RiftCast 后，双击安装包，按向导安装；升级可沿用原安装位置。完成后从桌面或开始菜单启动 **RiftCast**。

打开导播台右侧“回放”，点击事件即可跳转并切换镜头。事件下方可查看跟随目标，操作完成后面板会显示镜头结果。
