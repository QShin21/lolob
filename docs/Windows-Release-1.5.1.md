# RiftCast 1.5.1 · 国服观战数据适配

适配国服游戏文件版本 **16.21.832.5350**，恢复对应版本的观战基础遥测及回放伤害读取。

- 更新英雄、经济、经验、符文、冷却及资源信息的读取位置。
- 适配新版回放分片格式；通过完整回放十人输出与承伤的官方赛后累计校验。
- 团战区间使用对敌方英雄的伤害序列；累计数据保留本回放官方统计口径。
- 保留 1.5.0 的工作台和既有功能。

本次现场验证使用国服回放；实时观战分片已完成模拟测试，仍需实况验收。不同英雄、宠物和对局机制以运行时完整回放校验结果为准。详细记录见 `docs/CN-16.21.832-Maintenance.md`。

## 安装

退出当前 RiftCast 后运行 Windows x64 安装包，沿用原有赛事数据和设置。
