## 已完成

- 保存记录在任何 `await` 和 React 更新前取得同步事务门禁。相同事件回合第二次调用不会创建另一个 requestId。按钮禁用只是显示层，不承担事务保护。
- 一次保存固定标题、请求 ID、预期配置版本、席位和对局身份。`useBroadcast.send` 保留调用方提供的请求 ID；其他调用仍自动生成新 ID。服务端原有授权、CAS 和重复请求指纹检查保持原样。
- 已知的首次 4xx 校验/冲突拒绝允许修正后重新提交；网络、解析、连接变化、408 和 5xx 都保守视为结果未确认。重试沿用完整原请求，不刷新版本或生成新 ID。
- 不确定保存期间锁住标题，展示核对说明和原请求重试入口。席位或对局变化不允许重发旧请求。服务重启后须人工核对，因为服务端重复请求缓存本来就属于席位会话，不能承诺跨重启永久去重。
- 可以明确勾选已核对列表，再结束这次核对；该动作不发送保存请求。之后新的保存才是新事务。页面分类切换保留已访问的记录工作面，避免在途请求、核对状态或草稿因卸载丢失；不写入长期存储。
- 正式制作脚本三处数据表定位改为 `.data-grid-scroll`；原生可见性脚本关闭编辑器改用实际可访问名称。原行数、内容和窗口释放/恢复断言均保留。
