# RiftCast 1.1.6

## 本次更新

- 客户端 API 轮询间隔默认 **500 毫秒**，可调范围统一为 **100–1000 毫秒**。
- 设置界面、服务端校验和已保存配置的读取使用同一范围，保存后生效。
- 升级时保留范围内的已有设置；超过 1000 毫秒的旧设置调整为 1000 毫秒，缺失或无效设置恢复为默认 500 毫秒。

## 下载与安装

1. 在本页 **Assets（资源）** 中下载唯一的安装包 **RiftCast-1.1.6-Setup-x64.exe**。
2. 退出正在运行的旧版 RiftCast。
3. 双击安装包，按提示选择安装目录并完成安装。
4. 从桌面或开始菜单打开 **RiftCast 导播**。

进入“连接与输出 → 数据连接”，调整“客户端 API 轮询间隔（毫秒）”，点击“保存客户端设置”即可生效。接口响应较慢时会等待当前请求完成。
