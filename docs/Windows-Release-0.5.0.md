# RiftCast 0.5.0 Windows Release

2026-10-13。此版本包含当前工作区的自定义场景、原生预览修复和完整 Windows 桌面运行环境。

## 使用

双击 `RiftCast-0.5.0-Setup-x64.exe` 安装，随后从桌面或开始菜单打开 **RiftCast 导播**。安装支持选择位置，使用当前用户权限。无需另装 Node.js、npm、Electron 或 OBS，无需打开命令行。安装完成页关闭后从快捷方式启动。

免安装版为 `RiftCast-0.5.0-Windows-x64.zip`。先完整解压，再双击目录中的 `RiftCast.exe`。请保留同目录的 `resources` 和运行库。

应用内置官方 OBS Studio 32.2.2、原生投影辅助程序、英雄素材和对应 OBS 完整源码及许可证。首次运行从安装包复制独立 OBS 引擎，无需下载运行依赖。实际游戏数据接入、在线资源更新和推流按原功能需要网络。

## 数据

Release 的赛事、上传素材、资源缓存和 OBS 配置位于 `%APPDATA%\RiftCast`，启动日志位于其中的 `logs\director.log`。菜单「帮助 → 打开赛事数据目录」可以直接打开。安装更新与卸载保留此数据目录。

本机首次切换会复制原项目的 `data` 和内置 OBS 配置到 Release 用户目录，保留原项目文件。通用安装包和 ZIP 不包含本机的赛事资料、录制视频、推流码、OBS 密码或个人设置。原路径的录制片段引用继续依赖对应原视频文件。

Release 会拒绝复用正在运行的脚本数据服务；先退出旧导播窗口再启动，避免运行到旧版本。重复打开同一 Release 会聚焦现有窗口。

## 构建与验证

源码构建入口为 `npm run release:win`，产物保存在 `release/0.5.0`；构建记录包含源码基准提交、当前工作区状态、逐文件哈希、依赖版本和产物 SHA-256。服务端预先编译为 JavaScript，运行时直接使用安装包内的 Electron Node 环境。OBS 以独立进程运行；OCR 保留隐藏的 Windows 工作进程。

自动验证入口为 `npm run verify:release`。验证使用独立赛事数据与 OBS 配置，覆盖安装包内程序启动、0.5.0 健康接口、桌面页面、自定义场景、真实内置 OBS 连接、原生节目投影、重复启动和正常退出。它验证本机 Release 运行链路；真实对局、摄像头、直播平台推流和现场制作仍需要实测。

应用暂未配置 Windows 商业代码签名证书。此信息与官方 OBS 文件的来源和校验记录分别保存。产物完整性可核对同目录的 `SHA256SUMS.txt`。
