# RiftCast 0.8.0

## 本次修复

- 局内顶部保留英雄联盟原生比分、团队经济与地图目标显示。RiftCast 只在比分栏两端空白区域叠加队伍简称及系列赛胜场方格，其余顶部区域透明。自动 HUD 整理始终保留原生顶部比分。
- OCR 校准与个人经济/补刀识别共用原始游戏采样链路。优先使用 OBS 原始游戏源；失败时尝试采集完整可见的英雄联盟窗口。游戏被遮挡、最小化、退出时给出具体错误。载入一次采样后，校准主图及放大图使用同一张图片。
- 首发对位恢复旧版左右分队、每队五张竖版英雄/选手卡、底部系列赛比分布局。
- 包含此前工作区的抖音节目输出窗口及相关生命周期、音频和 TAKE 恢复修复。

## 安装与使用

双击 `RiftCast-0.8.0-Setup-x64.exe` 安装，或解压 `RiftCast-0.8.0-Windows-x64.zip` 后双击 `RiftCast.exe`。安装程序未签名。用户赛事与配置保存在用户目录，升级沿用既有数据。

进入真实数据模式并打开游戏观战或回放。在连接与输出中选择英雄联盟游戏窗口，再到来源与校准载入采样图。若 OBS 采样失败，请让游戏窗口完整可见且未被遮挡，再次载入。个人统计需等待局内 API 确认当前阵容；金币列显示 `当前金币(累计经济)` 时可以读取个人经济，装备视图可读取 KDA 与补刀。缺失或过期的数据保持不可用。

顶部定位按 16:9 默认观战 HUD 设置，其他 HUD 缩放需在 OBS 合成预监核对。编辑经 Preview → TAKE 进入节目。

抖音直播伴侣可选择独立的「RiftCast 节目输出」窗口；音频使用节目混音与 CABLE Output，避免重复采集。保持节目窗口打开且未最小化。首次开播前检查直播伴侣预览与声音同步。
