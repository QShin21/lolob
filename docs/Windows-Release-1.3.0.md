# RiftCast 1.3.0

整届赛事自动排赛、晋级和赛后数据归档。

- 新增赛事中心，支持 2–64 队的单败、双败、单 / 双循环、小组循环接淘汰赛、瑞士轮。一次填写参赛队伍、种子顺序、时间与 BO1 / BO3 / BO5 / BO7，生成整届赛程。
- 自动处理轮空、胜败者流转、小组晋级、瑞士轮配对和双败总决赛重置。可逐场调整时间和局数、补录副台赛果；已开展后续对阵的修订会提示影响范围。
- 单局结束自动归档，持续补采客户端结算、比赛详情和时间线。保存接口返回的完整原始字段，以及已观察到的十人数据、BP、事件、经济曲线、伤害、装备、符文和资源统计。
- 赛事中心统一展示积分、选手累计数据、逐局档案和采集状态。补录大场比分保留原因，单局数据按实际采集记录。
- 参赛战队队标和选手照片自动归集，其他赛事图片可以关联。支持整届 ZIP、完整 JSON、统计 CSV 和单局完整数据下载。

## 下载安装

展开本页 **Assets**，下载唯一安装包 **RiftCast-1.3.0-Setup-x64.exe**。退出旧版 RiftCast 后双击安装包，按向导安装；升级可沿用原安装位置。安装完成后，从桌面或开始菜单启动 **RiftCast**。

## 建立并运行一届赛事

1. 进入 **赛事 → 赛事中心 → 建立整届赛事**。
2. 选择已建档战队，或按“一行一队”批量输入队名；调整种子顺序，设置赛制、局数、开始时间及每场预留时间。
3. 点击 **生成整届赛事**。系统先按单比赛台顺序排期，可在“调整 / 赛果”中逐场修改时间。
4. 在可开赛对阵上按住 **载入**，完成连接和预监核对后切入节目。结束后自动保存单局数据并更新大场比分；局间沿用“赛后收尾 → 下一局”。
5. 查看 **积分排名、选手统计、逐局档案、赛事素材**，使用 **整届打包** 保存完整赛事文件。

小组赛按蛇形种子分组。循环赛胜 3 分、负 0 分；瑞士轮轮空 3 分，优先给尚未轮空的低分队。积分相同时比较净胜局、胜局、两队相互战绩及种子顺序；瑞士轮先比较对手积分和。常见偶数组、每组前二晋级时自动交叉对阵。

客户端返回的数据会原样保存到逐局文件。尚未返回的详情与时间线显示为等待采集或未取得，可保持客户端连接后重试。归档 ZIP 的 `manifest.json` 包含文件校验和及缺失项，统计中的缺失值保留为空。原始接口可用性取决于当前客户端与观战 / 回放环境；本地接口说明见 [Riot 官方文档](https://developer.riotgames.com/docs/lol#league-client-api)。

本版本的自动化验证使用隔离数据目录和合成比赛样本；实际赛事的客户端字段覆盖需在现场连接后核对。
