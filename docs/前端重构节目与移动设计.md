# 节目包装与移动协作：本批设计

在已独立核验的主工作台、数据、管理、帮助和收尾基础上继续，起点为记录保存修复 `b5bc70f`。依据完整 493 行任务书，以及 frontend-design 的先定构图、再实现、再看真实截图的方法。本批不是把旧节目样式再覆盖一层；拆出节目原语、分场景构图和固定画布规则。

## 选定方向与自审

保留 RiftCast / ARENA。节目使用石墨 `#101923`、工作底板 `#192835`、暖白 `#edf1ed`、次文字 `#b5c4cc`、蓝方 `#77c5ed`、红方 `#ef9188`，薄荷只作少量赛事强调。所有变量定义在节目根下，不读取控制台主题变量。字体沿用无需联网的 Bahnschrift / Segoe UI / Microsoft YaHei；比分采用等宽数字，中文姓名优先完整两行，空间不足有明确截断。

最初的“一套大标题加十张卡片”不足以呈现不同赛事任务，已放弃。识别点改为稳定的赛事身份条、对阵关系和按用途组织的数字。赛前用不对称对阵与倒计时；首发直接纵向配成五组；赛后将结果与数据分栏。BP 仍需要给舞台捕获留空，但历史分组横向展开为有界区域，不随着 GAME 5 一直向上长。live 与团战受真实合成几何约束，不能为视觉差异随意移动。

```text
赛前：赛事身份条 / 左：真实倒计时与赛制 / 右：蓝红两行队伍与系列比分
首发：赛事身份条 / 五列分路；每列蓝方选手、对位名、红方选手
BP：透明舞台 / 左右历史分组 / 蓝方五英雄、中央回合、红方五英雄
赛后：赛事身份条 / 左：胜方、系列比分、终局状态 / 右：团队比较与十人报告
移动：席位、控制者、同步 / 一个可切换监视 / 本席任务 / 合法的主动作
```

## 全部节目映射与保护

| 场景 | 本批结构 | 真实数据与保护 |
| --- | --- | --- |
| standby | 对阵与倒计时分栏 | 未设置、进行、结束各自文案；不伪造开播 |
| draft | 两队槽位与中央回合；有界历史 | 预选/锁定/最终归属分开；历史按稳定战队 ID；保留透明舞台 |
| lineup | 五组直接对位 | 保留所有十个位置；只读已接受名单；照片、英雄、缺图回退 |
| live | 在既有矩形内统一字级、色彩与对齐 | 五行黑底、顶部遮挡、原生英雄栏、小地图、摄像头位置不移动 |
| teamfight | 仍为空透明节目层 | 不添加标题、错误、字幕、队标、伪元素或装饰 |
| gold-ranking | 两组五名，名次与累计经济分离 | 真实累计排序、缺失占位、既有名次平移动效；避让字幕 |
| economy | 领先方摘要与曲线分栏 | 原始时间/穿零/缺口、来源与样本；不造预测线 |
| ranking | 五行双列榜单；单人另用焦点构图 | KDA、CS、等级、经济、七装备；不把装备价值冒充累计经济 |
| schedule | 左侧比赛日信息、右侧四行对阵 | 当前页、总页、BO、状态；无自动翻页 |
| postgame | 结果侧栏与十人冻结报告 | 冻结状态/缺失/胜方真实；无 MVP 推断 |
| interview | 名字、身份与主题两级名牌 | 左右停靠；不伪造视频；为字幕及面部留空 |

PGM 仍由上层 programState 解析，画布不得回读待播资料。现有手工 BP hold、名单保护、冻结报告和同局遥测链保持。自定义排版仍不冒充 OBS 的窗口/共享来源合成。

## custom 与五席剩余组合

- 编辑器三栏、点选/拖移/八向缩放/键盘微调已完成；本批补来源类型切换时保留“更换图层”对象、节目/串联单引用可见阻塞、合成核对的来源与快照说明。保留三类来源、fit 三种、负坐标与超画布范围、24 图层/50 场景、权限和上传保留。
- 移动资料/主导播可选内置及 custom；只读/字幕/回放席仍按真实权限，不新增设备枚举或远程图层编辑。补窄屏、软键盘、横屏的工作区及输入可达性，并呈现本席允许的状态核对。
- 字幕、暂停、回放、选手画面与 custom 的真实叠加遵循现有 OBS 来源组成；只显示已有状态和限制，不用浏览器自行补造引擎层。

## 检查边界

本批 Astra 只做构建与短隔离实现自审，截图属于实现检查。完整十一场景 1080p/720p、小播放器、长名称、缺图、GAME 5、经济缺口、分页、五席故障与自定义极限组合交 Sol 独立验收。原正式脚本断言不得削弱；结构改变需要明确更新定位并记录。

真实 Windows 标题栏/DPI/原生投影、OBS 合成、LoL、最终混音、伴侣、安装/便携和观众端继续未运行；不发布 Release、不改 main、不触碰真实 data/runtime/录像/恢复文件。
