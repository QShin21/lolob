# RiftCast 1.7.0 · 团队协作

主控端建立协作，团队成员在各自电脑的 RiftCast 中通过局域网或可达公网 IP 与端口加入。主控端统一管理 OBS 和最终直播推流。

- 持续共享主控游戏画面。协作者关闭本机游戏也能观看并提交节目切换请求。
- 协作者可共享自己的游戏视角，使用主控端包装；也可选择 OBS 投影窗口，共享完整节目。
- 默认由主控端批准切入；建组时可允许协作者的请求直接应用。提供成功、拒绝和失败回执。
- 单独的 TCP 协作端口，默认 3890，支持 IPv4、IPv6，最多 8 名协作者。配对通道使用 AES-256-GCM 加密、挑战验证及消息序列检查。
- 视频目标 720p / 30 fps / 约 4 Mbps；可选系统声音。远端画面断开时尝试恢复主控游戏来源。

公网可达要求由主控端承担。协作者主动连接，接收预览、上传画面及发送请求共用该连接。主控端的公网地址与协作 TCP 端口需允许外部访问；校园网的入站策略需现场核对。公网 IPv6 需要双方均有 IPv6 路径。

## 操作

1. 主控端进入“输出 → 协作”，填写名称和端口，点击“建立协作”。按网络条件允许该 TCP 端口入站，将地址和配对码提供给团队。
2. 主控端读取共享窗口，选择游戏窗口并开始共享。
3. 协作者在本机 RiftCast 的同一页面输入主控 IP:端口和配对码，点击“加入协作”。
4. 协作者观看主控预览并请求切换节目；自行 OB 的成员可先共享自己的窗口，再请求切入。主控端批准并核对 PGM 与声音。

停止输出并退出旧版后安装 1.7.0。用户资料沿用原有目录；协作配对信息不写入比赛资料。

## 验证范围

两套隔离实例验证连续双向视频、加密配对、请求与回执、页面切换持续共享；真实内置 OBS 验证远端画面解码、节目切入及本地录制。实际跨校园网公网接入与直播间接收效果需在目标网络试播核对。
