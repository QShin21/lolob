# 当前 HUD 与赛后归档

适用版本：RiftCast 0.2.0，2026-10-05。

工作台使用左侧大型节目、右上中型预监和右下及底部场景卡。桌面内置模式只为节目创建 OBS 原生投影，按配置显示 30 / 60 FPS；预监和设置页使用每秒 1 帧快照。Enter 和小键盘 Enter 将预监切入节目，按住按键只执行一次切入。

顶部比分、底部五行表格与经济卡使用不透明底色。原生比分遮挡区域与顶部卡片独立定位，底部表格保留游戏原生英雄属性区域与小地图。在 1920 × 1080 输出中，中央底部表格位于 x=496、y=829.4，宽 928、高 250.6；两侧选手画面各宽 190，左边分别为 x=306、x=1424。OBS 摄像头裁切使用相同坐标并随输出缩放。

底部表格按双方上单、打野、中单、下路和辅助对齐。从中间向外显示经济差、补刀与 KDA、选手 ID 与状态、英雄等级、召唤师技能、主符文与副系、装备、分路任务及饰品。静态图片使用官方资源；实时生命、资源、经验、大招与分路任务状态仅显示有效来源提供的值，缺失字段保持未知。

收到明确结束事件或客户端 EndOfGame / WaitingForStats 阶段后，程序自动保存本局记录并关联赛程。断线与 PreEndOfGame 阶段不会触发归档。胜方信息明确时只更新一次 BO 比分；胜方缺失时保留数据并提供人工确认。

选手数据和赛后报告读取归档快照。客户端退出、数据刷新或进入下一局后仍可查看上一局。结束阶段先于最终数据到达时，页面标注等待终局样本，仅允许同一局已核对的数据补全一次。

“下一局 · GAME N”保留战队、BO 比分和上一局归档，重置当前 BP、选手、计时、经济及事件，并将 BP 设为预监。节目继续保留当前画面，等待导播切入。胜方待确认或系列赛已结束时禁用下一局。

当前可复现检查与现场演练边界见 [验收说明](验收.md)。
