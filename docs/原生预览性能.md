# OBS 原生预览性能与验证

适用版本：RiftCast 0.2.0。当前桌面内置模式仅为节目创建原生投影，预监与设置页使用每秒 1 帧快照。

## 当前桌面显示路径

服务调用 `OpenVideoMixProjector` 打开内置 OBS 的节目投影；Electron 将原生窗口作为子窗口嵌入工作台最大的节目区域。图像由 OBS 自身的 GPU 显示路径输出，按配置使用 30 / 60 FPS。预监继续共享游戏捕获并采用独立 `?preview=1` HUD，使用每秒 1 帧快照；节目采用已切出的 HUD。

原生窗口按 16:9 适配可见区域，随页面滚动、布局变化及设备缩放重新定位。状态标识显示在投影上方。隐藏、暂停、页面卸载及应用关闭时关闭投影，恢复后重新创建；关闭完成前不复用旧窗口。

该能力限于 Windows Electron 桌面及应用拥有的内置 OBS。窗口操作核对 OBS 进程、节目标题及桌面宿主，预览控制接口限本机访问。浏览器或外部 OBS 的节目使用兼容 JPEG 订阅，界面标注“截图预览”；工作台预监和设置页均请求 1 FPS。桌面原生模式标注“原生显示”，FPS 数字来自 OBS 合成统计。

## 当前检查与现场测量

原生辅助程序自检及服务测试核对窗口归属、输入校验和生命周期；单屏工作流的隔离浏览器检查核对节目投影、页面释放和快照调度。复现方式见 [验收说明](验收.md)。

界面的 FPS 来自 OBS 合成统计。测量屏幕实际呈现率需要在当前单路布局下独立采集 Windows Present / Displayed 帧事件，同时观察渲染、编码和网络丢帧。此前双路布局的测量和验收脚本已随历史材料移出项目，当前单路布局的实际游戏运动与平台输出需要现场核对。

现场排查见 [推流流畅性](推流流畅性.md)。
