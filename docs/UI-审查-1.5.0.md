### UI-01：先为场景操作保留高度

`studio-dark-1366.png` 中场景列表可视高度仅 41px，首行正文也被下沿切断。关闭首次引导后，`studio-owned-dark-1366.png` 的场景列表为 96px；1366×736 为 81px，第二行仍被截断。1920×1080 可见高度达到 205px，说明问题集中在高度预算。

建议把首次引导收为紧凑入口，以完整场景行数确定监视器高度上限。首屏优先保留双监视、切入动作、关键混音与常用场景；说明性内容进入展开区域。搜索在 1450px 以下被隐藏，建议以图标展开或紧凑输入保留可达入口。

验收：1366×768、1366×736 均可同时看到 PGM、PVW、切入状态、切入按钮和至少两整行场景；首次引导显示时仍满足该目标；场景行文本与工具按钮不会被页底截断。1440×900 与 1920×1080 的空间分配同步检查。

### UI-02：把 BP 三类工作入口放到顶部

关闭引导后的 BP 页可视高度为 647px，内容高 1018px，“把英雄交给正确的选手”标题位于 y=761；初始引导显示时可视高度降至 592px。当前顶部只有“接管与差异”能直达下方任务，最终归属和规则仍依赖滚动寻找。

建议把“选禁英雄 / 最终归属 / 同步与规则”组织成首屏可见的工作入口，并保留当前双方 BP 概要。编辑区可采用并列、抽屉或紧凑视图；归属保存保持独立的确认语义。

验收：1366×768 首屏可发现最终归属、客户端差异与规则入口；每项最多一次点击进入；跳转后键盘焦点落在对应任务；关闭英雄抽屉后焦点回到原槽位；归属保存和 TAKE 的动作仍清楚区分。

英雄抽屉已有固定搜索与保存区，实际截图 `bp-picker-light-1366.png` 可作为保留结构。

### UI-03：设置目录按任务分组并支持检索

设置包含数据、画面、声音、输出、包装、诊断、协作、镜头、资源、转场、远程画面、演示、互动、集成和外观。关闭引导后目录可视高 605px，内容高 890px。首次打开时，下方任务不可见；切换到外观后，目录上部标题与常用项也会滚出视区。

建议按“连接与播出 / 节目制作 / 协作与工具 / 本机偏好”等用户任务分组，增加搜索或快速定位，并保持当前分组及选中项可见。左侧主导航的“输出”与目录中的“输出”使用不同层级说明。

验收：15 项任务全部有稳定入口；通过中文任务名称搜索可定位任一项；清空搜索恢复完整目录；方向键、Home、End 和 Tab 可用；从帮助跳转至指定设置后，选中项与内容标题一致并在视区内。

### UI-04：拆分包装长页，明确每个保存动作

`graphics-owned-light-1366.png` 对应滚动内容高 5035px，可视高 456px。首屏位置测得：赛前倒计时 y=1413，游戏原生 HUD y=3446，BP 统计 y=3678，赛程看板 y=4907。`graphics-bottom-light-1366.png` 同时显示图形组件保存区与页面固定保存区。

验收：首屏可选择全部包装子任务；任一高频设置最多一次点击定位；每个保存按钮能从标签或紧邻说明识别保存范围；切换子任务保留本地输入；全局与组件保存条不会用相同泛称同时竞争。预监图保持其广播配色。

验收：1366×768 声音页首屏完整显示桌面、解说、音乐的增益与静音、节目总线状态；设备配置入口可见；设备修改保留明确应用动作；未接入、静音、待采样等状态使用文字和视觉标记共同表达。

### UI-06：统一文字、间距与操作尺寸

场景说明、监视器页脚、安全栏多处使用 10–11px；场景收藏/编辑工具为 24×24px；音频设置按钮高 20px。与此同时，资源与 VDO 面板缺少与设置卡片一致的内部留白，造成密度突变。

建议操作正文以 14px 为主、元数据不低于 12px，固定状态条仅保留关键摘要；桌面图标按钮采用至少 32px，手机保持至少 44px；建立标题、正文、元数据、主操作、次操作的统一样式。

验收：场景与音频图标按钮具有可见 hover/focus 状态和可访问名称；主要文字不靠缩小至 10px 填入；13 场景、长队名、长文件名及提示文本均不覆盖相邻按钮。32px / 44px 是本轮产品设计目标；W3C AA 的基础目标尺寸为 24×24 CSS px，并规定了间距等例外：[Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)。

## 应保留的有效结构

- 顶层导航具备图标、文字与选中状态；安全栏固定在任务区之外，PGM / PVW 有文字和不同色彩标识。
- 本轮记录的桌面截图均无页面级水平溢出；390px 遥控页也无水平溢出。
- 主题由 `UiThemeProvider` 统一管理并持久保存；媒体和播出画面有独立样式边界。
- BP 英雄选择抽屉的搜索、当前槽位与底部保存区清楚；键盘 Escape 关闭后仍保留原界面。
- 设置任务、通用 TaskTabs 已有方向键与 Home/End 处理，改造导航时应延续。
- 资料草稿、保存到待播、切入节目和实际应用回执已有业务边界，新的视觉层次应强化这些动作差异。
