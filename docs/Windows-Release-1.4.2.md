# RiftCast 1.4.2 · OBS 切入与转场修复

修复 OBS 已连接时，点击 TAKE 持续显示“OBS 操作失败；节目内容未发布”的问题。

- 按 OBS WebSocket 协议清除场景转场覆盖设置，恢复硬切、淡入淡出和视频转场的节目切入。
- 转场结束后恢复原有场景转场名称和时长，保留未设置的字段。
- OBS 请求失败时显示具体请求名和错误码，便于定位来源、参数或设备问题。
- 保留 1.4.1 的国服 16.21 数据读取适配。

## 下载与安装

展开本页 **Assets**，下载唯一安装包 **RiftCast-1.4.2-Setup-x64.exe**。结束当前输出并退出 RiftCast，双击安装包完成更新，然后从桌面或开始菜单启动 RiftCast。

在制作台选择待播场景并点击 **TAKE**，确认切入状态显示“OBS 转场已完成，节目场景已确认”。现有赛事、素材和导播设置会继续使用。

安装包适用于 Windows x64，无需另装 Node.js 或 Python。
