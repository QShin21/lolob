# RiftCast 1.1.4

## 团战视图

移除“本段对英雄伤害”标题和右上角时长数字，保留十名英雄的状态、技能与各自伤害数字。移除左右选手照片、姓名框与摄像头画面，并在 OBS 预监、节目两条通道分别关闭团战场景的摄像头来源。普通局内场景仍可使用选手画面。

## 经济直接采集

经济采集默认使用国服只读遥测的个人当前金币和累计金币；每队经济由同一批次五名选手的累计金币相加。累计金币、排行榜、对位差值和经济曲线统一使用该来源。曲线按游戏时间每 5 秒保留最新样本，持续记录并留存在赛后报告。

经济设置页显示直读来源与采样状态，撤下金币 OCR 区域校准和人工金币输入。旧金币 OCR 设置不会覆盖直读数据；采样过期、阵容不完整或时间不一致时显示缺失。暂停与跳转继续按游戏时间处理。

辅助 OCR 可单独用于视野、KDA、补刀及顶部资源计数。历史 OCR 赛后记录继续可读，新的金币记录标注为“国服观战直读”。

国服只读配置对应 `16.20.824.8524`。安装新版后连接观战或回放即可自动读取，无需显示或校准原生金币列。
