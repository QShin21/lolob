# 自定义场景编辑器本轮实现记录

本记录只覆盖自定义场景编辑器实施片。工作分支为 `new`，开始时 HEAD 为 `d09da17`；本片不提交、不推送。业务基线为 main `7f2f399` / 0.7.0，已有直接操作算法来自本轮开始前的 `new`，不将旧布局作为设计约束。

## 设计依据与自审

已完整读取 `docs/前端设计实施方案.md`、固定版 `/tmp/riftcast-design-reference/frontend-design-SKILL.md`，以及 Library 最新任务书 `libfile_fa8f64dc18bc8191840dd744c317798c` 的 1–493 行（58822 字节）。三份输入与本片范围无冲突。

原编辑器的问题不只是侧栏宽度：命名放在右侧、保存放在底部，添加来源又长期占据左侧图层列表。操作者需要跨越三个区域才能完成一个对象的编辑。此次改为“场景顶栏＋图层／画布／当前对象”的连续工作面。

```text
返回导播  场景名称                 本地草稿  实际合成  保存到待播
图层＋添加来源 │ 点选／移动、比例、辅助线 │ 当前图层属性
上层覆盖下层   │                       │ 名称
图层列表       │     带留边的画布      │ 位置与尺寸
上移／下移     │                       │ 适配与显示
场景背景       │ 选中对象／排版示意     │ 来源与边界
保存进入待播；核对预监后 TAKE                键盘微调说明
```

自审后保留三栏关系，但彻底分离“选择来源”与“编辑已选图层”：来源选择是明确打开的中央任务面板；右栏不再重复场景名称。新增的缩放、辅助线、居中和来源更换均对应实际操作，没有多选、旋转、时间线等假控件。辅助文字仅在会影响操作判断处出现。

操作端颜色使用整合者维护的 `--ui-*` 变量，未定义另一套全局主题。媒体排版仍使用固定背景与媒体占位色，不随操作端深浅主题重染。整份 `custom-scenes.css` 已替换，没有尾部补丁或新 `!important`。

## 实际改动

| 工作区 | 本轮行为 |
| --- | --- |
| 顶栏 | 返回导播、场景名、草稿／服务器更新／处理状态、实际合成入口和保存到待播集中显示。名称重名、50 场景上限及无权限均有对应阻塞。 |
| 图层 | 列表上方覆盖下方，与 OBS 顺序一致；独立选择与显示按钮；上移、下移和移除固定在列表底部，长列表内部滚动。 |
| 画布 | 保留点选、拖动、八向缩放、1 px／Shift 10 px 微调；适合窗口或 25／50／75／100% 检查，缩放后可滚动；可显示中心辅助线。全部坐标仍为 1920×1080。 |
| 属性 | 按对象显示名称、位置尺寸、居中／铺满、适配、显示状态与实际来源。无图层选中时显示场景背景和画布事实。数值输入保留负号／空输入的编辑过程，并就近显示原范围。 |
| 来源面板 | 图片、应用窗口、已有 OBS 来源三个类型；图片缩略图和搜索；主机来源显式刷新；读取中、未读取、无匹配、失败、本机限制、OBS 未连接有不同说明。 |
| 来源更换 | 保留图层名称、位置、尺寸、适配与显示设置，更换同类型来源；失效引用可就地修复，无需删除图层重建。 |
| 实际合成 | 面板解释排版、PVW、TAKE 的关系。已保存且无本地修改／冲突、权限有效时，可明确执行“选择预监并返回”。未保存时仅提供“保存到待播并返回”。 |
| 失败与退出 | 保存、预监、上传失败保留本地内容；来源错误保留在相应区域。退出有放弃确认，上传图片保留。关闭编辑器恢复原触发点；来源面板关闭恢复触发点或画布。 |
| 窄屏 | 1100px 以下图层侧栏按需展开；820px 以下属性也按需展开。顶栏换行、主要触摸操作扩大；桌面低高度压缩顶底栏，属性和列表独立滚动。 |

图片浏览器载入失败现在显示准确的排版占位，不把失败图像当作正常内容。非图片来源始终标记为排版占位；没有把窗口列表、静态 DOM 或图片下载成功表述成真实 OBS 合成成功。

## 保留的业务接口与保护

- `save-custom-scene` 仍携带编辑器打开／人工核对后的 `expectedConfigVersion`。仅保存待播，成功后关闭；拒绝后保留本地草稿，不擅自覆盖新版配置。
- `preview-scene` 只由“选择预监并返回”明确触发。编辑器没有 `take` 调用，没有自动切入动作；来源读取、上传、来源选择、拖动及数字编辑都不选预监。
- `/api/obs/custom-sources` 仍受现有本地主机、主导播和连接条件约束。界面区分“最近读取可选择”与“实际捕获正常”，未承诺最小化窗口或断开会话可正常捕获。
- `/api/assets` 继续使用原上传接口与 `category=other`；保留 PNG／JPEG／WebP／GIF 与单张 8 MB 限制。移除图层、退出草稿均不调用素材删除。
- 1920×1080、X −1920～1920、Y −1080～1080、W 1～3840、H 1～2160、24 来源、50 场景、实色背景、三种 fit 均与服务端一致。`custom-scene-geometry.ts` 没有修改。
- 原生 `<dialog>.showModal()`、取消／焦点返回仍保留；与 `native-preview-layout.ts` 的 `dialog[open]` 遮挡检测兼容。来源面板是普通编辑任务区，没有将侧栏伪装成模态弹窗。
- 对话框隔离键盘冒泡；数字输入、来源搜索及编辑器 Enter 不进入全局 TAKE。画布微调不处理输入法组合状态或 Ctrl／Alt／Meta 组合。
- 中途失去权限／连接时停止编辑并取消尚在进行的指针手势，保留其他草稿；只读状态仍可查看图层与属性。
- 共享 OBS 来源明确保留原输入内容与音频，修改影响全部引用者；没有复制、删除借用输入或承诺冻结外部共享内容。窗口捕获不显示鼠标、不独立采集该应用音频的原规则不变。

## 文件边界

- `src/components/CustomSceneEditor.tsx`：场景草稿、实际接口、工具状态和编辑工作面。
- `src/components/CustomSceneSourcePicker.tsx`：新增领域组件，负责来源搜索、类型与选择反馈；数据读取和应用仍由编辑器持有。
- `src/components/custom-scenes.css`：工作面、来源面板、对象属性和响应式样式；保留共享 `CustomSceneLayout` 的媒体边界。
- `docs/编辑器本轮实现记录.md`：本记录。

没有修改共享 App、tokens、ProductionDesk、SceneLibrary、入口文件、后端或几何算法。
