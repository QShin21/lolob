# 系统外观 · RiftCast 0.4.1

发布日期：2026-10-07。

## 切换方式

1. 打开左侧「连接与输出」，选择「外观」。
2. 选择「浅色风格」或「深色风格」，界面立即更新，无需额外保存。
3. 偏好保存在当前浏览器或桌面客户端；刷新、关闭后重开会沿用选择。同源浏览器标签页会同步更新。

首次使用保留深色风格。浅色采用浅灰背景、白色面板与深色文字，覆盖导航、工作台、设置、表单、管理页面和协作界面。选择项支持键盘操作并显示当前选中状态。

主题只控制操作界面。节目、预监中的赛事画面、场景缩略图及 `/overlay` 输出保持 ARENA 原有播出配色。主题切换不发送赛事配置修改或切入操作。

## 保存与升级

偏好使用本地存储键 `riftcast-ui-theme`。不同浏览器配置、桌面客户端及其他设备各自保存；清除站点数据后恢复默认深色。存储不可用时仍能切换当前页面，并在外观设置中提示无法保留选择。

更新源码后运行 `npm run build`，或使用 `启动导播.ps1 -Rebuild`，然后重新打开客户端。已有赛事资料和 OBS 设置继续使用。

应用版本统一从 `package.json` 读取，显示于侧边栏、使用指南、桌面帮助菜单和 `/api/health`。赛事归档的 `version: 0.3.0` 继续表示既有导出格式。

## 验证

主题浏览器验证使用生产构建、隔离演示数据和独立 HTTP 服务，关闭 OBS 自动启动及游戏连接。复现命令：

```powershell
npm test
npm run build
node scripts/verify-ui-theme.mjs
npm run verify:production
node scripts/verify-director-workflow.mjs
node --check electron/main.cjs
```

界面脚本需要 Playwright；可用 `RIFTCAST_PLAYWRIGHT_MODULE` 指定现有模块的绝对路径。主题报告及截图保存在本机被 Git 忽略的 `verification-output/ui-theme-0.4.1`。具体检查结果见 [验收说明](验收.md)。本轮验证范围为界面及隔离服务，真实游戏、OBS 原生画面、摄像头和平台推流需现场核对。
