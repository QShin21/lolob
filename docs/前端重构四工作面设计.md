## 构图与自审

沿用已建立的六色播控 tokens：底色 #11151B、工作面 #181E26、控件面 #222A34、正文 #EFF3F7、次文字 #ADB8C7、品牌 #70D7C2；浅色由同一语义变量切换。系统中文字体，正文 14px，辅助 12px，标题 20px，数字等宽。节目自己的颜色不读取控制端 tokens。

最初把四页都整理成卡片网格仍然延续旧结构，不能满足这次重构。因此按任务采用不同构图：数据是比较表与检查区，管理是对象列表与详情，帮助是问题目录与操作说明，收尾是本局核对表与后续动作。沿用固定全局应急条，页面内部滚动；不增加营销大标题和装饰编号。


## 业务覆盖矩阵

| 工作面 | 真实读取与写入 | 保护和恢复 | 本批边界 |
| --- | --- | --- | --- |
| 十人、分队、对位与个人 | players、有效统计/经济、静态装备；select-player 与 preview-scene | 不补零；累计/当前/装备价分开；选手检查不写节目，设焦点后须 TAKE | 新工作面；节目包装下一批 |
| 经济、事件与来源 | 原 EconomyChart、冻结记录、EconomySourcePanel / OcrCalibration | 保留曲线缺口和坐标实现；实际采样/人工经济是即时动作 | 不连接真实捕获；OCR 实机待补 |
| 赛程和战队 | set-schedule、set-teams、load-match；稳定队/选手 ID | 编辑草稿独立；expectedConfigVersion；冲突保留；载入前展示双方与影响 | 保留全部字段，不改后端语义 |
| 素材和记录 | 原资产上传/引用/透明裁切；比赛 JSON/CSV 与录像地址 | 上传不播出；无素材删除能力不增加；归档保持冻结与缺失 | 英雄授权链不动 |
| 帮助与诊断 | 实际连接状态、版本、hotkeys、sceneInfo；页面/设置任务导航 | 导航不执行连接/设备安装；不编造实际用户目录 | 桌面日志用现有 IPC；安装/便携实机未运行 |
| 本局收尾 | finalize-game、accept-final、correct-result、remake、next-game、save-recording | 使用实际结果键、尝试和冻结快照；保留理由、按住保护和服务端阻塞 | 不发真实输出/录制命令进行验证 |
| 输出结束 | 各路实际状态与独立停止入口 | RTMP、摄像头、声音、REC 不归并为一个状态；伴侣先结束直播 | 真实音画仍交授权实机验证 |

当前席位和主控制权仍由服务端裁决；不扩大 LAN、OBS、文件或设备权限。管理页不能用编辑后的队名替换 PGM。所有提交继续经现有 send，保留 revision/requestId/CAS；保存、预监、TAKE、应用、人工核对仍分开。
