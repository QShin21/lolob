- 团战视图增加十人状态栏：英雄头像、等级、终极技能、召唤师技能、经验条、血条和资源条。技能沿用冷却遮罩和最后十秒数字，头像保留死亡倒计时及男爵、远古龙增益边框。状态栏向上留出每位选手的伤害框，六套风格同步适配。
- 局内、团战、经济榜、经济曲线和数据榜的左上角统一显示中立资源状态。支持虚空巢虫、峡谷先锋、男爵、元素亚龙和远古龙；刷新时缩为图标，等待刷新时显示倒计时，未知状态显示“—”。计时跟随游戏时间，暂停和回放跳转同步处理。
- 国服 `16.20.824.8524` 观战读取增加中立生物与营地刷新标记，能够在回放跳转后恢复实际剩余时间。按精确游戏文件哈希启用配置，使用现有只读进程通道。
- 赛后报告新增第三页“伤害对比”。保留团队总览的其余布局，把英雄经济对比替换为官方赛后对英雄伤害。左右各占半侧，十人最高伤害为 100%，其余条长按同一最大值计算；蓝方从左、红方从右向中间延伸。零伤害显示 0，缺失数据显示“未采集”。原有两页保留。
- 团战分段统计在实际 TAKE 进入团战时建立基线；再次切入重新开始。重复刷新、预监和浏览器重连不重置本段。累计值回退、英雄替换和回放跳转会终止该段数据有效性。

## 伤害数据状态

国服 `16.20.824.8524` 已接入逐次伤害解析：真实观战从当前游戏的观战分片持续采集，ROFL 回放从本地文件解析，再按当前播放时间提取累计值。实际 TAKE 进入团战时开始统计本段对英雄伤害；物理、魔法、真实伤害分项同时保留。无需 League Broadcast 或 BlueBottle 账号。

请先确认连接状态出现“实时观战伤害”或“回放逐次伤害”，再切入团战。观战服务器只保留近期分片，中途启动的采集具有明确起点，之后的团战可正常统计。官方赛后总伤害用于全场报告。版本不匹配、分片断档或无法确认完整基线时显示“—”；恢复采集后重新切入团战。导出文件注明逐次伤害的采集起点。

## 使用

在“赛后报告”页码控制中选择“伤害对比”，预监确认后 TAKE。官方赛后数据补录到对应已保存对局后即可使用；没有对应数据时保留“未采集”。

团战视图保留透明游戏区域。观战端切换到适合团战的原生布局，检查底部状态栏、两侧选手画面和小地图的位置。中立资源计时会随局内节目切换持续呈现，无需单独开启。

六套风格包沿用 v1 格式，既有配置继续可用。安装程序、完整 ZIP、六套风格包与三套 BP 英雄素材库继续提供。

## 验证范围

包含 Windows 自动化测试、六套风格的团战与第三页报告浏览器检查、1920／1280／960 宽度边界检查、原有节目回归，以及打包程序中的赛后数据恢复和页码操作。样例验证覆盖真实零值、缺失值、十人共同最大值、镜像方向、暂停、过期样本及重新切入。

国服回放已读取十名英雄状态、存活男爵、男爵重生倒计时及海洋亚龙重生倒计时。完整回放的 3,925 次对英雄伤害重建后，十名英雄累计值取整均与官方赛后统计一致。真实观战已验证雷恩加尔、塞拉斯等英雄随播放产生伤害增量。此版本配置限定上述精确游戏构建；后续游戏更新需要重新适配和验证。真实客户端 BP、OBS 合成及平台播出未计入本次通过项。
