# 观战遥测与计分板

## 数据与显示

计分板通过本机 Live Client Data 获取选手、装备槽位、召唤师技能名称、死亡状态和复活剩余时间。国服只读采样器补充生命、资源、累计经验、金币、技能槽位冷却和增益。按队伍与英雄名称匹配十名选手，显示名与选手排序变化不会改变数据归属。

冷却使用游戏时间中的绝对结束时间 `readyAt`，总冷却使用 `totalCooldown`。图标变暗，扇形遮罩随游戏时间减少；剩余时间大于 10 秒时隐藏数字，最后 10 秒向上取整显示秒数。回放暂停时停止转动，倍速跟随游戏时钟；采样过期或回退后状态失效，等待当前画面的新样本。

R 图标来自指定版本的 Data Dragon 英雄资料。未学习的大招显示为灰色，缺失冷却显示为未知。装备按价格重新排列后仍通过原始槽位与装备 ID 绑定冷却。原生读取当前覆盖装备技能槽位；未提供技能槽位的装备被动冷却需要另外适配，不能由装备静态说明推算。充能技能当前显示已读取的可施放冷却，未新增充能层数进度界面。

ID 下方依次为紫色经验、绿色生命、蓝色法力／黄色能量。经验根据当前版本的峡谷累计升级阈值换算，并核对原生等级与 API 等级。非标准经验模式无匹配阈值时保留未知。其他资源类型保留原始资源量。

个人金币移至 ID 与补刀／KDA 之间，分两行显示余额与括号中的累计金币。死亡头像灰度处理，并在中央显示复活倒计时；男爵增益使用紫色框，远古龙增益使用灰白色框，两者同时存在时使用双框。增益过期、死亡或采样失效后移除边框。

## 当前读取配置

- 系统：Windows x64；单个 `League of Legends.exe` 进程。
- 已验证游戏文件版本：`16.20.824.8524`。
- 文件 SHA-256：`EE3C887B4579AEAB12CA77B2A43CC1CC3411A8AA30BC43D2DFEA856F6CE497C8`。
- 只在 Live Client Data 返回完整观战名单、没有活动玩家且 Replay API 返回相同进程 ID 时接入。
- 游戏文件校验失败时停止原生采样，继续使用可用的官方 API 数据。设置 → 数据 → 观战遥测显示连接状态。
- 采样器只请求 `PROCESS_VM_READ | PROCESS_QUERY_LIMITED_INFORMATION`，使用有界 `ReadProcessMemory`。不向游戏写内存，不加载 DLL，不安装驱动，不调用游戏内部函数。
- 单个样本包含明确采样时间与游戏时间；原生样本超过 3 秒后失效。游戏升级后需要重新核对字段并增加匹配配置，不能仅修改版本字符串。

原生采样源码位于 `scripts/native/observer-reader.cs`，通过隐藏的 PowerShell 工作进程加载，安装包包含源码与启动脚本，无需另外安装 Python 或 Node.js。进程退出、句柄失效、名单不完整或字段超界均报告不可用。完整原始内存与账号凭证不落盘。

## 伤害数据边界

`telemetryDamage` 支持对英雄伤害、承受伤害、物理／魔法／真实对英雄伤害。`telemetryDamageSource` 记录 `api`、`memory` 或 `postgame` 来源。记录 JSON 和 CSV 保留这些数据，新字段未接入节目画面。

当前游戏版本的实时伤害累计内存字段尚未确认，原生采样器不会伪造伤害值。Live Client Data 实际提供相关累计字段时会保存；对局结束后，可通过匹配同一对局 ID、同队同英雄的官方 LCU 赛后统计补录。后续终局样本不会清空已保存的伤害数据。回放无对应官方赛后数据时，伤害列保持“不可用”。血量差、技能理论伤害与击杀事件不会作为伤害统计替代来源。

## 验证

- `node --import tsx --test server/telemetry.test.ts`：计时、十秒边界、过期、身份匹配、装备槽位、增益与伤害归档。
- `node scripts/verify-telemetry-hud.mjs`：隔离浏览器中的图标、扇形遮罩、倒计时、布局、暂停和数据过期显示；通过 `RIFTCAST_PLAYWRIGHT_MODULE` 指定测试浏览器模块。
- `node scripts/verify-observer-live.mjs`：只读采集正在运行的匹配国服观战／回放，输出去除选手账号名称的验证报告；不操作游戏、播放进度、OBS 或推流。

模拟数据的渲染通过、原生真实读数通过、OBS 合成与平台直播验收是分别记录的验证范围。当前真实采样已验证十名英雄的生命、资源、经验、金币及使用后的召唤师技能／饰品冷却；男爵、远古龙和特定主动装备仍需对应事件发生时的真实画面对照。

## 参考

数据模型参考 [League Broadcast JavaScript SDK](https://github.com/BlueBottleGG/leaguebroadcast-js-client) 的绝对游戏时间冷却和槽位索引。旧版 [LeagueBroadcast Farsight](https://github.com/floh22/LeagueBroadcast/tree/v2/LeagueBroadcast.Farsight) 展示了外部只读采样方式。原生实现与当前版本配置在本项目独立实现并与本机实际样本核对；新版 League Broadcast 后端源码与官方赛事导播系统未包含在本项目中。
